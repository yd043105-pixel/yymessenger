Design the existing native teacher room reservation editor in 여양고 온라인 교무실. Use the project's existing design system and Korean labels.

Group room selection and reservation title clearly. Group start date/time in one panel and end date/time in another. Label all controls and display 한국 시간(KST) and 24-hour time. Use native date/time picker affordances. Include the existing save action and existing back navigation. Keep room availability or overlap errors readable beside the relevant input and preserve the entered draft after a failed save.

Consider keyboard avoidance, small phones, enlarged fonts, invalid end times, occupied rooms, server failures, and a disabled save while processing. Do not create a new booking workflow, invented permissions, or a fake success state. This is an Android/iOS native design reference.
