Design the main organization screen of 여양고 온라인 교무실, a native Windows teacher messenger. Use the project's existing design system. This screen is a design reference for WPF.

Default window dimensions: 450×820. Fit a compact title bar, signed-in teacher identity, search field, and a clear organization tree. Show school, departments, and teachers with online/offline labels, selection checkboxes, and meaningful hierarchy. Use synthetic names only. Preserve message/file sending and the online/offline right-click menu; include only implemented actions.

Group access to received/unread/sent messages, favorites, chat, surveys, tasks/submissions, school notices, timetable, calendar/reservations, and settings. Prioritize the organization tree. Use scrolling when needed; do not replace the compact messenger with a wide dashboard.

Show the active selection and a compact received-message count. Provide a discoverable appearance setting. Keep long names readable and keyboard focus visible. Consider loading, empty search, and disconnected server states. Respect existing permissions. No invented SMS/mail actions or new navigation functions.
