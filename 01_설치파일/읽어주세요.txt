설치파일 찾기 — 1.0.0 시험본

01_서버PC : yymessenger-1.0.0-server-setup-win-x64.exe
  서버 설치 마법사입니다. 업무 서버 역할에는 관리자 메신저도 포함됩니다.
  같은 폴더의 서버 ZIP은 수동 배치용으로, EXE 설치 시 따로 풀 필요는 없습니다.
02_교사PC : yymessenger-1.0.0-setup-win-x64.exe
  교사 PC에는 이 파일만 설치합니다.
03_안드로이드 : teacher-Signed.apk / family-Signed.apk
  교사용과 학생·학부모용 시험 앱입니다. 실제 파일명은 kr.school.yeoyang으로 시작합니다.
04_iOS : yymessenger-1.0.0-ios-build-source.zip
  Mac 제작 담당자에게 전달할 소스입니다. iPhone 설치용 IPA가 아닙니다.
  이 폴더의 Mac 시뮬레이터 바로가기도 실제 iPhone 설치파일과 다릅니다.

다른 기기로 옮길 때는 해당 실제 파일과 SHA256SUMS.txt를 함께 복사하세요.
.LNK 바로가기 대신 EXE·APK·ZIP 원본 파일을 전달하세요.
전달파일목록.json에는 버전·파일 크기·해시와 시운행 상태가 기록되어 있습니다.

처음 시험할 때는 02_설명서/00_설치와_기능테스트_안내.pdf부터 읽으세요.
Android는 Debug 시험용이며, iPhone 서명·학교 배포자 코드서명·정식 공개 릴리즈는 별도 준비입니다.
05_Mac : Mac 교직원 메신저 시험본
  Apple Silicon은 arm64-trial.zip, Intel은 x64-trial.zip을 사용합니다.
  Mac전달파일목록.json과 00_Mac설치안내.txt를 확인하세요.
  Developer ID 서명·Apple 공증 전 시험본이며, 기존 7개 전달파일 목록과 별도로 검증합니다.
