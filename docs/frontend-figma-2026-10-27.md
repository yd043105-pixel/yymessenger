## 실제 프로그램에 반영한 부분

- PC는 작은 조직도 크기를 유지하면서 왼쪽 메뉴 폭을 78로 줄이고, 교직원 이름 옆에 직책을 표시한다. 긴 직책은 생략하고 마우스를 대면 전체를 보여준다.
- 공통 제목줄 높이를 44에서 38로 줄였다. 메시지함의 반복 안내 문장을 없애고 제목·본문에 공간을 더 줬다. 메시지 목록과 상세 제목은 한 줄 생략을 유지하며 답장은 본문 스크롤 밖에 고정한다.
- 작성창은 본문 공간을 확보하도록 높이 660을 사용한다. 수신자 두 줄 스크롤, 예약·파일 제출 요청 한 줄, 드래그 첨부, 글꼴 서식, 임시저장 목록은 기존 동작을 유지한다.
- 앱은 학교명·역할과 ‘내 정보’ 버튼을 상단에, 홈·메시지/소식·내 정보를 하단에 고정한다. 가운데 내용만 스크롤한다. 서버에서 받아 온 학교명을 표시하며 로그아웃 시 초기화한다.
- 두 앱의 공통 카드·입력칸·버튼·소식 목록에 색상과 여백을 적용했다. 바로가기의 이중 테두리와 소식 카드의 굵은 세로 장식을 줄였다. 소식 제목은 한 줄로 생략하고 누르면 전문을 확인한다.
- 모바일 터치 영역은 44 이상을 유지한다. 항목 제목 전문과 버튼의 접근 가능한 이름을 유지하고, 상단 내 정보 아이콘에 설명을 붙였다. 약관 항목과 동의 체크, 권한에 따른 메뉴 노출은 그대로다.
- PC의 다섯 색상 테마와 유리 효과 선택을 유지한다. 읽는 영역은 불투명한 흰색으로 정리하고 유리 느낌은 상단과 배경에 둔다. 실시간 흐림 처리·새 애니메이션·외부 글꼴 라이브러리는 추가하지 않았다. 고대비 모드는 Windows 시스템 색상을 따른다.

## 같은 날 재검토와 보완

- 보조 글자 `#63748C`는 흰 배경에서는 4.76:1이지만 옅은 화면 배경에서는 4.40:1, 선택 배경에서는 4.17:1이었다. `#5A6B82`로 바꿔 각각 5.44:1, 5.02:1, 4.76:1로 높였다. 조직도 검색 안내의 별도 옅은 글자·아이콘 색도 공통 색상으로 연결했다. [W3C의 일반 글자 대비 안내](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)를 참고한 해당 조합의 개선이며, 앱 전체 접근성 인증을 뜻하지 않는다.
- 부모·학생의 시간표에 ‘내 수업 / 학급’이 함께 표시돼 의미가 혼동될 수 있었다. 교사용은 ‘내 시간표’, 학생·학부모용은 ‘학급 시간표’로 구분했다. 다른 바로가기도 ‘상담 예약’, ‘학교 일정’, ‘특별실 예약’, ‘수강신청’으로 줄이고 기존 기능·권한은 유지했다.
- 앱 하단에서 그림 위에 글자 버튼을 겹쳐 배치하던 구성을 네이티브 버튼의 위쪽 이미지 배치로 바꿨다. 글자가 커지면 그림·글자와 메뉴 높이가 함께 배치된다. 320pt 콘텐츠 폭에서 하단 버튼 글자 크기를 두 배로 설정하고 실제 iOS 컨트롤의 그림·글자 경계가 겹치거나 잘리지 않는지 확인하는 회귀 검사를 추가했다. OS 전체 글자 크기를 바꾼 실기기 검사를 대신하지 않는다.
- 본문과 하단 메뉴를 작업 중 비활성화할 때, 새로 고정한 상단 내 정보 버튼도 함께 비활성화하도록 맞췄다. 작업 완료 후 복구되는지도 검사한다.
- 메시지·공지 시각은 기기 현지 시간대, 홈의 오늘 날짜는 한국 시간대를 쓰고 있었다. 목록 시각도 한국 시간(KST)으로 통일했다. 서버의 UTC 저장·예약 처리·파일 보유 기한에는 손대지 않았다.
- Figma의 PC 창 제어 글자가 제목 바로 뒤에 붙어 있던 배치를 오른쪽 끝으로 옮기고 실제 프로그램과 같은 38 높이를 적용했다. 공통 보조 글자 변수도 갱신했다.

기존 권한·메시지·예약·제출 흐름은 WPF 회귀 검사, 수정한 모바일 탐색·학교 기준 시각은 iPhone 시뮬레이터 검사에서 확인한다. 이번 변경의 캡처와 실행 결과는 `artifacts/ui-review-20261027/`에 보관한다. 검증 완료 여부는 해당 커밋의 GitHub 실행 및 보고서와 함께 확인한다.
재검토 결과: [e23988e 코드 검증](https://github.com/yd043105-pixel/yymessenger/actions/runs/40456124037)의 Windows·Android·iOS 세 작업이 모두 통과했다. 로컬 WPF 시운행은 93개, iPhone 16 / iOS 26.5 시뮬레이터는 54개 검사에 통과했다. 54개에는 한국 시간 표시, 320pt 콘텐츠 폭에서 하단 글자 두 배, 작업 중 상단 버튼 잠금·복구 검사가 포함된다. 로컬 두 Android APK와 Windows 설치파일을 재생성했으며 전달 파일 7개 해시·현재 소스 일치 검사도 통과했다. 실제 Android/iPhone과 OS 전체 큰 글씨 설정을 통한 사용성 확인은 남아 있다.

PC 기본 시안은 실제 프로그램처럼 아이콘과 글자를 함께 표시하고, 메시지·학교 업무 분류의 파랑·초록 배경을 구분했다. 새 노드·색상 변수 기록은 `figma-rail.json`에 보관한다. 마지막 자동 캡처는 Figma 무료 도구 한도로 거부되어, 저장 후 브라우저에서 선택된 450×820 조직도 화면을 직접 확인했다. 메뉴·설정이 프레임 안에 들어오는 구조 검사도 통과했다. 한도 도달 전의 `figma-pc.png`는 이 마지막 아이콘 보정 이전 캡처다.

## 시간표·상담·할 일과 파일 제출 후속 개선

사용자가 지정한 세 번째 연결 계정에서 편집 권한을 확인했다. [후속 세부 화면 3개](https://www.figma.com/design/x3w6KOP0uIi5VnkEDbXx0l?node-id=32-15)를 기존 변수·글자 스타일·버튼 인스턴스로 추가했다. 시안의 데이터는 모두 가상이다. 세 화면의 하위 요소가 화면 밖으로 넘치지 않는지 확인하고 최종 캡처를 검토했다. 노드 기록과 시안 캡처는 `artifacts/ui-review-20261027/detail-design-state.json`, `detail-design.png`다. PC 시안은 제출 현황을 넓게 보여주는 860×760 예시이며 실제 기본 창은 860×650과 본문 스크롤을 유지한다.

- 앱 시간표는 교시·시간과 과목·교사를 나눠 표시하고, 변경된 수업은 배경·변경 표시·변경 전 내용으로 구분한다. 수업 없음과 일자별/기초 시간표 적용 정보는 유지한다. 조회 중 날짜·학급 선택도 잠가 응답과 선택값이 어긋나지 않게 했다. 날짜 API는 기기의 달력·문화권과 관계없이 `yyyy-MM-dd`로 보낸다.
- 상담 예약은 날짜·학생 선택을 같은 카드에 정리했다. 학부모·학생에게 교사용 설정 카드 전체를 숨겨 빈 카드가 남지 않게 하고, 교사용 신청 시작 날짜·시간은 예약 개방 시각 지정 스위치를 켰을 때 함께 표시한다. 닫힌 시간에는 신청 버튼을 만들지 않는다. 기존 담당 학급 권한과 요청 재시도 ID는 유지한다.
- Windows 할 일/제출 창은 현재 탭을 강조하고 긴 목록 제목과 보조 정보를 각각 한 줄로 표시한다. 전체 문구는 마우스를 대면 확인할 수 있다. 창과 목록은 기존 색상 테마를 따르고, 상단 버튼은 좁은 폭에서 다음 줄로 배치한다. 제출 탭에서 ‘할 일 직접 추가’를 누르면 할 일 탭으로 전환한 뒤 작성한다.
- 제출 현황의 제출/미제출/면제 인원은 강조 카드로, 제출자는 개별 카드로 묶었다. 일괄 다운로드와 할 일 저장은 기존 기본 동작 버튼 스타일로 강조하고 종료는 보조 버튼으로 구분했다. 파일 내려받기·면제·요청 종료의 기존 처리와 권한 검사는 유지한다.
- 회귀 검사에 상담의 역할별 설정 카드, 열린/닫힌 시간, 자녀별 학급 전환, 예약 개방 설정 표시를 추가했다. 시간표 검사는 같은 수업 카드의 교시·실제 시간·수업 없음 접근성 설명을 함께 확인한다. Windows 검사는 제출 탭에서 직접 할 일 등록까지 이어지는 동작을 확인한다.

이번 후속 변경의 최종 빌드·실행 결과는 GitHub 해당 커밋의 Verify 실행과 로컬 전달 파일 검증 결과로 확인한다. 버전은 1.0.0을 유지하며 공개 릴리즈·스토어 업로드는 실행하지 않는다.
