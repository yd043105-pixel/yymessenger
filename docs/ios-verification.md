# iOS 1.0.0 시운행 기록

2026-10-08 GitHub의 실제 Mac 실행 환경에서 .NET SDK·워크로드 10.0.401, Xcode 26.6을 사용했다. 최종 제품 코드 `30beb2429c2d3839758e675322b709cddb197a62`의 [Verify 실행](https://github.com/yd043105-pixel/yymessenger/actions/runs/37730207885)에서 Windows·Android·iOS 작업이 모두 성공했다. 태그·릴리즈·TestFlight·App Store 공개는 하지 않았다. 버전은 1.0.0, 모바일 내부 빌드 번호는 2다.

## iPhone 시뮬레이터

새 iPhone 16 시뮬레이터와 iOS 26.5에서 가상 학교 서버·공지 서버를 실행하고 네이티브 앱을 설치했다. 버튼의 실제 앱 처리 함수를 호출해 화면과 서버 동작을 검사했으며, 앱 프로세스를 종료한 뒤 다시 실행하여 로그인 복원을 확인했다. 실제 손가락·키보드 입력을 자동화한 시험이나 iPhone 실기기 시험으로 표시하지 않는다.

실행 검사 14개가 통과했다.

- 보통의 재실행에서 Keychain 데이터 유지, 새 설치에서 이전 데이터 제거, 잠금 해제 후 해당 기기만 사용하는 접근 등급
- 내장 1.0.0 변경 내용, 외부 HTTP 주소 거부, 보호자 로그인·허용 공지 표시·비밀번호 입력 제거
- HTML처럼 보이는 공지의 일반 문자열 표시와 읽음 처리, 모든 페이지 내용 가림, 세션 확인 후 화면 복원
- `FileResult`를 통한 공지 전용 첨부 업로드·게시, 별도 교직원 서버의 업무 메시지 조회
- 실제 앱 프로세스 재시작 후 자동 로그인, 로그아웃의 저장 정보 제거, 복사한 이전 쿠키의 서버 접근 회수

## Release 확인

검사 전용 코드를 포함하지 않는 Release 시뮬레이터 앱도 빌드했다. 실제 번들의 표시 버전 1.0.0·내부 번호 2, 로컬 네트워크·사진 저장 권한 문구, `PrivacyInfo.xcprivacy` 포함, 전체 HTTP 허용 설정과 Debug의 localhost 예외가 없는 것을 확인했다. iPhone용 배포 인증서를 사용한 서명·IPA 생성 시험은 아니다.

## 남은 실제 기기 시험

iPhone·iPad 실기기, iOS 15 등 이전 지원 버전, 운영 HTTPS·학교 VPN, 로컬 네트워크 권한 거절·허용, 문서 선택기의 실제 파일 선택·공유·사진 저장, 실제 OS 잠금·최근 앱 화면, VoiceOver·큰 글꼴·가로 화면은 학교 시험에서 확인해야 한다. 자동 검사의 화면 가림은 앱의 처리 함수를 검사한 것으로, 모든 OS 전환에서 정보가 노출되지 않는다는 보장이 아니다.

CI artifact에는 시험용 시뮬레이터 ZIP·화면·결과와 패키지 잠금 파일만 포함한다. ZIP은 Mac의 Simulator용이며 iPhone에 설치할 수 없다. 일반 사용자가 설치할 IPA와 TestFlight 시험에는 학교의 Apple 서명 환경이 필요하다. 준비 절차는 [iOS 운영 안내](ios-operations.md)에 있다. APNs 푸시는 이번 범위에 포함하지 않았다.
