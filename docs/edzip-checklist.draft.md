# 필수기준 체크리스트 작성용 대응표

2026-10-24 · 검토용 · 공식 제출본이 아님

공식 서식에 대신 체크하거나 서명한 자료가 아니다. 아래 ‘준비 상태’는 인증·법적 충족 판정이 아니다. 미확정 항목을 해결한 뒤 실제 근거 파일·쪽수에 맞춰 공식 HWP의 충족/미충족/해당 없음 중 하나를 작성한다.

제품: 여양메신저 학교 통합 소통 시스템 / YY Messenger · 1.0.0 출시 전.
공급자: 교사 개인 개발. 운영 학교는 설치 학교별로 별도 설정한다.
접속: Windows 설치형 메신저와 교사용·학생 및 학부모용 Android/iOS 앱. 공개 운영 주소 미설정. 브라우저 웹앱으로 소개하지 않는다.
