# 선택과목 신청 운영 안내

2026-10-23 · 1.0.0 시험 배포용 · 과목별 정원 없음

학생은 ‘여양고 학교 소식’ 앱으로 신청하고, 교사는 Windows ‘여양고 교무메신저’에서 수강신청 업무를 설정한다. 기존 두 서버를 함께 업데이트해야 한다. 별도 웹앱이나 서버 프로그램을 추가로 켤 필요는 없다.

## 1. 관리자가 준비할 일

1. 두 서버를 백업한 뒤 이번 버전으로 함께 교체하고 재시작한다. [기기별 설치와 테스트 순서](installation-and-test-order.md)를 따른다.
2. 학급·재학생과 과목 담당 교사를 등록한다. 과목 담당 교사는 학교 소식 서버의 교사 계정과 교내 계정이 연결되어 있어야 선택 목록에 표시된다.
3. 관리자 계정으로 PC 메신저에 로그인하고 왼쪽 **수강신청**을 연다.
4. **수강신청 담당자 권한**에서 담당 교사에게 권한을 부여한다. 관리자는 기본적으로 관리할 수 있다. 일반 교사는 전체 신청 명단을 볼 수 없다. 권한을 해제하면 이후 관리 요청부터 차단된다.

## 2. 담당 교사가 신청을 열기

1. **수강신청 → 새 신청 회차**를 선택한다.
2. 회차명과 학기, 대상 학년을 입력한다. 현재 재학 기준 1·2학년 중 하나 또는 둘 모두를 선택하며 3학년은 제외한다. 학급별 개설은 하지 않는다. 예: ‘2027학년도 2학년 선택과목 신청’, ‘2027-1’.
3. 시작·종료 시각을 한국 시각 `yyyy-MM-dd HH:mm`으로 입력한다.
4. 선택 묶음을 만든다. 예: ‘탐구 선택’, 선택과목 2개. 과목명·유형(공통과목/일반선택/진로선택/융합선택)·학점·교과를 입력하고 담당 교사 버튼에서 교사를 선택한다. 학점은 학교 교육과정을 확인하여 직접 입력하며 1~20 범위의 정수를 받는다. 이 입력 범위가 법정 과목 학점 기준을 뜻하지는 않는다.
5. 공통과목은 학생 화면에서 필수로 자동 선택되며 선택과목 개수에서 제외된다. 공통과목만 있는 묶음은 선택 개수를 0으로 둔다. 회차별 최소·최대 신청 학점은 공통과목을 포함한 합계이며, 0은 해당 제한을 사용하지 않는다는 뜻이다. 실제 가능한 선택 조합이 없으면 저장할 수 없다.
6. **초안 저장** 후 확인한다. 정원 입력 항목은 없으며 같은 과목을 몇 명이 신청해도 접수된다.
7. 상세 화면에서 **신청 공개**를 누른다. 시작 시각 전에는 조회만 가능하다. 공개 후 과목·대상·선택 규칙을 편집할 수 없으므로 미리 확인한다.

## 3. 학생이 신청하기

1. 학생 본인 계정으로 ‘여양고 학교 소식’ 앱에 로그인한다.
2. 홈의 **선택과목 신청 · 내 신청**을 누른다.
3. 회차를 열고 유형·과목명·교과·학점을 확인한다. 과목 검색과 유형 필터를 사용할 수 있으며, 필터로 숨긴 과목도 기존 선택을 유지한다. 공통과목은 체크를 해제할 수 없다. 각 묶음의 선택과목 개수와 신청 학점 조건을 충족한 뒤 신청한다. 과목 선택만으로 접수가 완료되지는 않는다.
4. 내 신청 내역을 확인한다. 기간 안에는 변경·취소·재신청할 수 있다.
5. 연결 끊김이나 다른 기기와 충돌 안내가 나오면 내 신청을 새로 조회한다. 오래된 화면의 선택만 보고 접수 완료로 판단하지 않는다.

학부모 대리 신청은 제공하지 않는다. 이번 교사용 휴대폰 앱에 수강신청 관리 화면을 추가하지 않았다.

대상은 현재 학교에 등록된 학년으로 판단한다. 선택한 학년의 모든 반과 이후 추가된 반의 재학생에게 적용하며, 같은 학년 안의 반 이동은 신청 자격에 영향을 주지 않는다. 신청자·미신청자 표에서는 확인 편의를 위해 학급별 필터를 계속 제공한다.

기존 학급 대상 회차는 서버 시작 시 해당 학급이 속한 1·2학년 전체 대상으로 한 번 전환한다. 신청 내역과 버전은 유지하며 3학년은 포함하지 않는다. 원래 대상 학급이 삭제되어 학년을 확인할 수 없거나 3학년만 대상이었던 회차는 대상 학년이 비어 학생에게 표시되지 않는다. 이런 초안은 담당자가 학년을 다시 선택해야 한다. 적용 전 백업하고 두 서버·PC 메신저·학생용 앱을 함께 업데이트한다.

## 4. 마감하고 분반을 확정하기

1. 상세 화면에서 신청자·미신청자와 과목별 신청 수를 확인한다. 신청 상태·학급·학생 이름으로 명단을 필터링하고 총 학점과 과목을 확인한다. 대상 외 학년으로 이동하거나 재학 상태가 바뀌어 대상에서 빠진 신청 수는 별도로 표시한다.
2. 필요하면 **신청 마감**으로 일찍 닫는다. 종료 시각이 지나도 학생 신청·변경·취소는 자동 차단된다.
3. 마감 후 **분반 확정**을 실행한다. 현재 유효한 신청자를 과목별 새 분반에 등록하고 담당 교사를 연결한다. 미신청자는 자동 배정하지 않는다.
4. 기존 **분반 관리**에서 확정 명부를 확인하고 분반 공지를 보낸다. 신청 내역이 기존 확정 분반을 자동 덮어쓰지 않는다.
5. **현재 표 CSV 저장**은 현재 학급·상태·이름 필터를 적용한다. 학생 이름·학급·총 학점·과목 유형·선택 과목이 포함되므로 학교가 승인한 장소에만 보관한다. 졸업 파기가 외부 CSV나 이메일 사본까지 원격 삭제하지는 않는다.

유형·학점 기능은 두 서버와 PC 메신저·학생용 앱을 함께 업데이트해야 한다. 기존 저장 회차의 학점 정보가 없으면 임의로 3학점 등을 채우지 않고 미설정 상태로 읽는다. 기존 초안을 다시 편집·공개할 때는 학점을 입력해야 한다. 공개된 기존 회차의 신청 상태를 자동으로 바꾸지는 않는다.

참고한 고교학점제 사이트의 로그인 뒤 신청표는 현재 확인하지 못했다. 해당 사이트의 이미지·문구·화면 소스는 사용하지 않았고 학교 앱의 기존 구성요소로 과목 카드와 관리 표를 구현했다.

개인 시간표 자동 생성은 포함하지 않는다. 과목·분반을 실제 수업 시간대에 연결할 자료가 추가로 필요하다.

## 시험할 순서

가상 학급·학생으로 먼저 시험한다. 담당자가 아닌 교사와 학부모가 신청·관리 API를 사용할 수 없는지, 대상 학생 두 명이 같은 과목에 모두 신청되는지, 필수 개수 오류가 차단되는지 확인한다. 변경·취소·재신청, 기간 외 차단, 미신청자 표시, 마감 후 차단, 분반 확정 후 공지 대상까지 확인한다.

수강신청 개인정보 안내를 `config/registration-policy.draft.json`과 `docs/policies`에 추가했다. 초안의 운영 승인 값은 꺼져 있으며 학교 검토 없이 운영 가입을 활성화하지 않는다.
