홈페이지는 https://gyomutalk.tinyrat.chatgpt.site 에 본인 전용 미리보기로 게시했다. 공개 접근은 별도 선택 사항이다. 다운로드 버전은 GitHub 최신 정식 공개 릴리즈에서 읽으며, 현재 공개 릴리즈가 없어 준비 중으로 표시한다. Mac·휴대폰 앱은 출시 예정으로 유지했다.

확인하지 않은 사항: 실제 다음 정식 릴리즈를 이용한 사용자 기기 전체 업그레이드, 학교의 운영 백업 장치·UPS·방화벽 정책, Mac Developer ID 서명·Apple 공증. Mac 시험본의 ad-hoc 서명 무결성 검사는 일반 배포 승인을 뜻하지 않는다. Windows 업데이트 파일의 Ed25519 서명은 Authenticode 인증서를 대신하지 않는다. 휴대폰 앱에는 PC 업데이트 엔진을 추가하지 않았다.

기존 설치본에는 새 업데이트 엔진이 없으므로 갱신한 설치본을 한 번 설치해야 한다. 학교 운영 데이터·실제 계정·터널·SMTP 설정은 이번 작업으로 변경하지 않았다.
