# 1.0.0 배포 준비용 변경 내용

아직 배포하지 않은 개발 버전입니다. 학교 담당자의 배포 지시 전까지 버전은 1.0.0으로 유지하며 태그·릴리즈를 만들거나 공개하지 않습니다.

Windows x64용 교사용 앱과 학교 서버를 함께 제공합니다. 압축을 완전히 풀고 README를 확인하세요.

- 로그인·계정 승인, 쪽지·첨부파일, 채팅, 설문, PC 직접 원격 지원
- 교직원 웹 조회, 개인 할 일, 파일 제출 요청·현황·일괄 다운로드·미제출 알림
- SHA256SUMS.txt로 압축 파일의 SHA-256 해시를 확인할 수 있습니다.
- 업데이트 후 로그인하면 새 기능·개선·버그 수정 안내를 표시합니다. 확인한 버전은 다시 자동 표시하지 않으며 PC·앱·웹의 업데이트 내역 메뉴에서 다시 볼 수 있습니다.

교직원 서버는 교내망 운영용입니다. 학생·학부모 공지를 위한 별도 외부 서버와 교내 서버의 발신 연결, Windows 공지 작성·현황 기능을 추가했습니다. 외부 서버는 교직원 DB·개인 메시지·원격 지원을 제공하지 않습니다. 담당 학급과 학교가 확인한 보호자 관계에 따라 접근을 제한하고 공지 첨부도 30일 후 삭제합니다.

Android·iPhone용 MAUI 앱 소스를 포함하며 Android 시운행 APK는 별도 빌드합니다. 실제 외부 운영은 도메인·HTTPS·별도 서버 설정이 필요하고, 스토어 출시는 학교의 서명·개발자 계정과 실제 기기 검증이 필요합니다. iOS 빌드·서명, 백그라운드 푸시와 앱 내 자동 업데이트는 아직 제공하지 않습니다. docs/mobile-operations.md에서 준비 항목을 확인하세요.

업데이트 전에 서버를 종료하고 기존 데이터 폴더를 별도 보존하세요. 기존 데이터 경로·인증서·백업 설정을 유지한 채 서버와 교사용 앱을 함께 교체하세요. 자세한 절차는 압축 파일의 docs/releases.md를 참고하세요.

CI는 서버 기능과 독립 실행 배포본을 검사합니다. 실제 Windows 키보드 입력과 두 교직원 PC 사이의 원격 지원은 릴리즈 공개 전에 별도로 확인하세요.
