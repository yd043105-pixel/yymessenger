Windows x64용 교사용 앱과 학교 서버를 함께 제공합니다. 압축을 완전히 풀고 README를 확인하세요.

- 로그인·계정 승인, 쪽지·첨부파일, 채팅, 설문, PC 직접 원격 지원
- 교직원 웹 조회, 개인 할 일, 파일 제출 요청·현황·일괄 다운로드·미제출 알림
- SHA256SUMS.txt로 압축 파일의 SHA-256 해시를 확인할 수 있습니다.

교내망 운영용입니다. Android·iPhone 앱과 학생·학부모 외부 공지, 앱 내 자동 업데이트는 아직 포함하지 않습니다.

업데이트 전에 서버를 종료하고 기존 데이터 폴더를 별도 보존하세요. 기존 데이터 경로·인증서·백업 설정을 유지한 채 서버와 교사용 앱을 함께 교체하세요. 자세한 절차는 압축 파일의 docs/releases.md를 참고하세요.

CI는 서버 기능과 독립 실행 배포본을 검사합니다. 실제 Windows 키보드 입력과 두 교직원 PC 사이의 원격 지원은 릴리즈 공개 전에 별도로 확인하세요.
