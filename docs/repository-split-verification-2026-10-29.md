# 교무톡·학교톡 명칭 및 제품별 저장소 분리 점검

확인일: 2026.10.29. 버전은 1.0.0이며 정식 Release를 발행하지 않았다.

## 운영과 고지

- 학교가 역할별 자체 서버와 데이터·계정·백업을 운영한다. 중앙 학교 검색은 승인된 학교명·지역·ID·역할별 HTTPS 접속 주소를 안내한다.
- 학교 검색 등록 승인과 학교 자체 도입 결재를 구분한다. 원본 내부결재·보안·개인정보 자료는 학교에 보관하며 개발자 신청 메일이나 공개 저장소에 첨부하지 않는다.
- 교육현장 경로는 학교장 승인, 교육현장 적용 범위 판단, 자체 보안대책을 확인한다. 일반기관용 제출 문서와 CSAP 증빙을 일괄 요구하지 않는다. 기록 하나에 필요한 내용을 함께 담았다면 동일 파일을 각 근거로 참조할 수 있다.
- 다른 학교·역할의 기록 재사용, 미확정·만료·변조 문서, 미승인 수신 주소·메일 수신처를 차단하는 통제는 유지한다. 이 동작을 기관의 법적 승인이나 보안 인증으로 표시하지 않는다.
- Android·iOS의 교사용 이름은 교무톡, 학생·학부모용 이름은 학교톡으로 설정했다. 기존 앱 ID와 세션·저장 경로는 유지한다.

Windows 분리 과정에서 설치 검사가 통합 패키지의 이전 출력 경로를 참조하는 문제를 수정했다. 시험 산출물 이름과 SHA-256 대조표가 일치하도록 제품별 파일명을 반영했으며 실제 다운로드한 산출물의 체크섬도 대조했다.

모바일 검증: https://github.com/yd043105-pixel/yymessenger/actions/runs/40796809565
Android·iOS 검증 모두 통과했다. iOS 실제 시뮬레이터 실행과 Release 번들 검사에서 교사용 교무톡·학생학부모용 학교톡의 표시 이름, 기존 앱 ID, 버전·HTTPS 설정을 확인했다. 실기기 서명·App Store 업로드를 수행한 결과는 아니다.

각 저장소는 필요한 공통 소스를 포함하고 출처·공통 파일 해시를 기록한다. 네 번째 공통 저장소를 요구하지 않는다. Mac 실제 실행 검사는 고정한 서버 저장소 커밋을 합성 시험용으로 사용하며 학교 운영 서버와 연결하지 않는다.

공개 소스에 실제 운영 첨부·DB·백업·승인 문서가 섞이지 않도록 원본의 전체 Git 제외 규칙과 전용 보호 폴더 규칙을 적용했다. 실제 개인정보 파일을 생성하지 않고 3개 저장소의 예시 경로 27개를 git check-ignore로 확인했다. 이 규칙은 파일 내용의 개인정보 검사를 대신하지 않으며 강제로 추가하거나 다른 경로로 복사한 자료는 별도 점검이 필요하다.

기존 저장소의 PC·Mac 통합 빌드와 Windows 릴리즈 워크플로는 새 제품 저장소로 이관했다. 모바일 검증과 앱 원본은 기존 저장소에 유지한다. 설치된 제품의 자동 업데이트나 자동 공개 배포를 이번 작업으로 활성화하지 않았다.

## 로컬 및 전달본 확인

- 교육현장 예외를 포함한 도입 기록 검사 72개, 관리자 실제 UI 검사 46개, 학교 검색 검사 13개, 실제 다중 학교 격리 검사 2개 통과.
- Android 시험 APK의 실제 애플리케이션 라벨이 교무톡·학교톡인지 확인했다. 공개 스토어 업로드는 수행하지 않았다.
- 사용자 전달본은 실제 파일 30개이며 설명서는 4권 16쪽이다. 개인정보 제외 검사, 미확정 설정 상태, 문서·약관 원문 일치, Mac ZIP 무결성과 복사 해시를 검사했다.
- 설명서·설정 예시는 학교별 공통 내용이며 앱의 저작권·등록 연락처는 요청에 따라 유지한다. 승인 문서 원본·운영 DB·학생 명부·비밀 설정을 전달본에 포함하지 않았다.

실제 학교의 결재·예외 적용 판단·개인정보 처리·네트워크·인증서·메일·백업·스토어 심사는 별도로 수행한다. Mac 일반 배포용 Developer ID 서명·공증과 iOS 실기기 설치본 배포를 완료한 결과가 아니다.
