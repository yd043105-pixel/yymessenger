# 화면 개선 및 교직원 접속 상태

버전은 1.0.0을 유지한다. 실제 서비스 공개·스토어 배포와는 별개인 개발 변경이다. 2026-10-27의 시각 기준과 Figma 파일은 [최신 화면 개선 기록](frontend-figma-2026-10-27.md)을 따른다.

## 화면 방향

Windows 메신저와 교사용 앱, 학생·학부모용 앱은 각각 유지하며 기존 학교 서버를 통해 연결한다. 웹 화면으로 대체하지 않는다.

- PC는 기본 450×820의 작은 조직도 창을 유지한다. 연락처·메시지·학교 업무를 구분하고 미확인 메시지는 상단에서 바로 연다.
- 이름과 검색창의 가독성을 높이고 부서의 펼침·접힘을 필터 전환 후에도 유지한다. 새 부서는 기본으로 펼친다.
- 앱은 학교 이름과 작은 역할 표시, 두 열의 업무 바로가기, 최근 메시지·공지를 중심으로 구성한다. 하단 세 개 탐색 메뉴와 기존 기능은 유지한다.
- PC 왼쪽 툴바는 스크롤 없이 모든 항목을 표시한다. 창 폭이 420 미만이거나 아이콘과 글씨를 함께 표시할 세로 공간이 부족하면 아이콘을 숨기고 텍스트만 표시한다. 다시 넓히면 아이콘이 복원된다. 글씨 크기는 줄이지 않는다.
- 조직도·즐겨찾기는 별도 분류 제목 없이 배치한다. ‘메시지’는 파란 배경, ‘학교 업무’는 초록 배경의 제목으로 구분한다. 고대비 모드에서는 운영체제 색상을 따른다.
- ‘가정통신문’은 학생·학부모 앱에 보내는 가정통신문 및 일반 공지 화면이다. 기존 대상 학급·분반 선택과 열람 권한은 유지한다.
- ‘수강신청’은 서버가 `canManage` 권한을 확인한 지정 담당자와 관리자에게만 표시한다. 로그인 및 평소 새로고침 때 권한을 다시 확인하고, 열기 직전에도 재확인한다. 조회에 실패하면 항목을 숨기며 실제 업무 API도 기존 서버 권한 검사로 보호한다. 관리자는 ‘수강신청 → 수강신청 담당자 권한’에서 담당자를 지정·해제한다.
- 기본 색은 학교 파랑 #245BC6, 본문 #182C47, 보조 #5A6B82, 구분선 #DFE7F1, 선택 배경 #EAF0FC, 화면 배경 #F3F6FB이다. PC는 맑은 고딕, 모바일은 운영체제 기본 한글 글꼴을 사용한다. 제목은 중간 굵기, 본문은 보통 굵기, 날짜·보조 정보는 작은 크기로 구분한다.
- 특징은 작은 상태 아이콘과 부서 중심 명단이다. 장식용 큰 카드·강한 그림자를 줄이고 기존 다섯 색상 테마와 선택 가능한 유리 효과를 유지한다. 유리 효과를 꺼도 내용을 읽을 수 있다.

- [Dooray 메신저](https://dooray.com/main/service/messenger/): 대화와 학교 업무를 연결하는 탐색 구조.

업체의 로고·화면·이미지를 복사하지 않고 학교에 맞게 자체 화면을 구현한다.

## 접속 표시 규칙

| PC 연결 | 교사용 휴대폰 앱 | 명단 표시 |
|---|---|---|
| 연결·사용 중 | 무관 | 초록색 채운 원, 온라인 |
| 연결·자리비움 | 무관 | 주황색 시계 원, 자리비움 |
| 연결 없음 | 로그인 후 앱 사용 중 | 파란색 휴대폰, 휴대폰 접속 |
| 연결 없음 | 연결 없음 | 회색 빈 원, 오프라인 |

이름 왼쪽 작은 아이콘에 약 0.5초 마우스를 대면 상태 글씨가 보인다. 색상 외에도 시계·휴대폰·빈 원으로 구분하며 화면 읽기 도구에도 상태 이름을 제공한다.

여러 PC를 사용하는 경우 하나라도 사용 중이면 온라인이다. 연결된 모든 PC가 자리비움이면 자리비움이다. PC가 연결되어 있으면 PC 상태가 휴대폰보다 우선한다. ‘접속 중’ 필터는 PC 온라인 및 휴대폰만 접속한 사람을 포함하고 자리비움은 별도 필터로 제공한다.

휴대폰만 접속한 사람에게도 쪽지를 보낼 수 있다. PC 원격지원 메뉴는 PC 연결이 있을 때만 표시한다. 휴대폰 아이콘이 PC 원격제어 권한을 만들지 않는다.

## 자동 자리비움

기본 5분 동안 마우스·키보드 입력이 없으면 자리비움으로 바뀐다. 입력하면 온라인으로 복귀한다. Windows 잠금도 자리비움으로 처리한다. ‘설정 → 화면·자리비움’에서 2·5·10·15·30분을 선택할 수 있다.

Windows 기본 입력 경과 시간만 5초 간격으로 읽는다. 키 내용·마우스 좌표를 수집하지 않으며 입력 훅을 설치하지 않는다. 상태가 바뀔 때만 서버에 알리고 서버는 연결별 변경을 3초 간격으로 제한한다. 활동 기록이나 시간은 데이터베이스에 저장하지 않는다.

## 휴대폰 연결과 보안

교사용 앱이 로그인한 상태로 앞에 열려 있을 때만 45초 간격으로 연결을 갱신한다. 앱이 뒤로 가거나 로그아웃하면 연결 종료를 요청한다. 정상 종료 요청이 전달되지 않는 강제 종료·통신 장애는 마지막 갱신 후 90초에 만료한다. PC의 명단 재조회 주기를 포함하면 비정상 연결 해제가 화면에 반영되기까지 약 2분 걸릴 수 있다. 로그인 정보를 저장해 두었다는 이유만으로 계속 접속 중으로 표시하지 않는다.

기존 교내 교직원 서버의 인증·CSRF·접속망 제한을 그대로 사용하는 두 개의 POST 경로를 추가한다.

- `/api/presence/mobile`: 본인의 현재 로그인 세션 연결 갱신.
- `/api/presence/mobile/leave`: 본인의 해당 세션 연결 종료.

서버가 인증된 계정과 기기 세션으로 소유자를 결정한다. 다른 사람 ID를 보내 상태를 바꿀 수 없다. 만료·철회된 세션은 즉시 무효로 본다. 한 휴대폰 연결을 닫아도 다른 유효한 휴대폰 연결은 유지한다. 상태는 메모리에만 존재하고 서버를 다시 켜면 초기화된다. 학생·학부모 서버에는 이 경로와 교직원 명단을 추가하지 않는다.

실제 교내망/VPN 및 학교 휴대폰 정책에 따른 접속 가능 여부는 별도로 확인한다. 이 변경을 위해 학교 방화벽·백신·공유기를 수정하지 않는다.

## 메시지 미리보기와 할 일 선택

메시지 목록의 내용은 한 줄로 표시하고, 넘치는 부분은 말줄임한다. 직접 작성한 제목이 있으면 제목을, 없으면 본문 앞부분을 표시한다. 문장을 재작성하거나 AI로 요약하지 않는다. 제목은 선택 입력이다. 비우면 서버가 본문 앞부분을 제목으로 사용하고, 원문 전체는 그대로 보관한다. 예약 전송에도 같은 규칙을 적용한다. 상세 제목도 한 줄로 표시하며, 자동으로 만든 제목은 본문과 중복 표시하지 않는다. 답장 버튼은 본문 스크롤 밖 우하단에 고정되어 있고, 메시지를 선택했을 때 활성화된다.

받은 메시지를 열면 해당 메시지에서 추출된 본인의 미확인 할 일 후보만 말풍선에 표시한다. 사용자는 후보별 체크를 바꾸고 ‘추가하기’를 누른다. 선택한 후보는 진행 중인 할 일이 되고, 선택하지 않은 후보는 제외된다. ‘추가 안 함’은 표시된 후보 전체를 제외한다. 결정은 서버에 저장되어 같은 메시지를 다시 열어도 묻지 않는다. 추가한 할 일의 제목·기한·완료 여부는 기존 할 일 목록에서 수정한다. 추출은 기존 날짜·요청 표현 규칙을 사용하며 외부 AI API를 호출하지 않는다.

`GET /api/todos?sourceId=메시지ID`는 다른 할 일의 목록 페이지와 무관하게 해당 메시지의 후보를 조회한다. 기존 소유자·수신 권한 검사를 유지하므로 다른 사용자나 관리자에게 개인 할 일을 노출하지 않는다. 후보 결정은 기존 CSRF 검사와 수정 버전 검사를 거친다.

## 메시지 작성과 임시저장

수신자 영역은 두 줄 높이로 고정하고 초과 인원은 내부 스크롤로 확인한다. 파일 제출 요청과 예약 전송은 한 줄에 배치한다. 본문 도구에서 현재 Windows에 설치된 글꼴, 크기, 굵게·기울임·밑줄·취소선, 글자 색과 배경 강조를 선택할 수 있다. 파일은 작성 창이나 본문·첨부 영역으로 끌어 놓거나 파일 선택 버튼으로 첨부한다.

서식은 HTML·RTF·XAML 문서를 전송하는 방식 대신 검증된 텍스트 조각으로 저장한다. 본문과 서식의 원문이 일치해야 하며, 글꼴 이름·크기·색·조각 수를 서버에서 제한한다. 외부 글꼴 주소나 실행 가능한 문서·이미지 개체는 허용하지 않는다. 붙여넣기는 일반 텍스트를 받는다. 서식은 일반 전송·예약·받은 메시지·암호화된 PC 메시지 사본에 유지된다. 교사용 Android·iOS의 공통 화면도 강조를 표시하고 Windows 글꼴 파일은 전송하지 않는다. 휴대폰에는 시스템 기본 글꼴을 사용한다.

‘임시저장 목록’에서 메시지별 저장 시각, 수신자 수와 첨부 수를 보고 다시 열거나 삭제한다. 새 작성 창은 새 메시지로 시작하며, 이전 내용은 목록에서 불러온다. 작성 중 창을 닫으면 해당 초안에 자동 저장한다. 다른 초안을 열기 전에는 현재 내용도 별도로 저장한다. 전송에 성공하면 전송한 초안만 삭제하고 다른 초안은 유지한다. 저장 위치는 사용자 PC의 앱 데이터 아래 `drafts/<학교 서버·계정 구분값>/`이며 Windows 계정의 DPAPI로 암호화한다. 같은 Windows 계정을 장악한 공격자나 로컬 관리자까지 방어하는 저장소는 아니다.

이전 버전의 단일 임시저장은 목록으로 옮긴다. 변환 실패 시 원본을 보관하고, 서버 전송 여부가 불분명한 초안은 동일 요청 번호로만 재시도하게 한다. 첨부파일 자체를 초안 폴더에 복사하지 않으므로 원본 파일을 옮기거나 삭제하면 다시 첨부해야 한다.
