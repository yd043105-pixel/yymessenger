# 휴대폰 앱 화면 개선

기존 학교 디자인에서 사용한 남색·파랑을 유지하면서 Android와 iOS의 네이티브 앱 화면을 정리한다. 버전은 배포 승인 전까지 1.0.0이다.

## 화면 구성

- 홈: 학교 이름, 사용자 인사, 학부모 자녀 선택, 시간표 진입, 변경 알림, 최근 학교 소식.
- 소식: 수신 권한이 있는 공지 목록과 미확인 필터. 교내 교직원 모드에서는 메시지 목록으로 표시한다.
- 내 정보: 자녀 연결 또는 학생 고유번호, 약관·개인정보 안내, 업데이트 내역, 로그아웃.
- 로그인: 학교 표시, 이용 공간, 서버 주소, 아이디·비밀번호, 자동 로그인, 개별 가입·초대 가입.

하단 메뉴는 스크롤 영역 밖에 배치한다. 공지 카드는 제목·발신자·게시일·미확인 상태를 구분해서 표시한다. 홈은 최근 네 건을 보여주고 나머지는 전체 목록에서 확인한다. 아직 구현되지 않은 급식이나 제출 기능의 결과를 임의로 표시하지 않는다.

## 시각 기준

본문 남색 `#17243B`, 주요 동작 파랑 `#2563EB`, 보조 글자 `#64748B`, 배경 `#F5F7FB`, 구분선 `#E2E8F0`, 선택 배경 `#EEF4FF`를 사용한다. 한글은 기기의 기본 글꼴을 사용하며 화면 제목 24, 카드 제목 16, 본문 14, 보조 정보 11~12의 크기로 구분한다. 기본 글자 확대 기능을 유지하고 버튼의 최소 터치 높이는 44이다.

기존에 크게 노출하던 설정 버튼과 빈 오류 영역을 홈에서 정리한다. 자녀 미연결 계정에는 연결 안내를 표시하고 학교 소식이나 시간표는 요청하지 않는다.

## 확인 범위

실행 캡처는 가상 계정·가상 학교 소식으로 생성한다. Android에서 하단 메뉴, 자동 로그인, 공지 열람·작성·첨부·회수, 로그아웃을 검사한다. iOS는 같은 공통 화면 코드와 변경된 메뉴 동선을 시뮬레이터 검사에 반영한다. 학교·가족별 서버 접근 권한, 인증정보 보관 방식, 백그라운드 화면 가림은 유지한다.

서버 구조나 앱 배포 방식은 이번 화면 개선에서 변경하지 않는다. 교사용·학생 학부모용 설치 패키지 분리와 남아 있는 관리자 화면의 앱 이전은 별도 작업이다.
