합계 119개. 검사 수는 실행 사례 수이며 보안 인증이나 실제 학교 규모의 성능 보증이 아니다. Windows 교체 시험은 학교 서버가 아닌 격리한 시험 폴더에서 수행했다. 백업 장치를 실제로 분리한 시험은 아니며 시험 폴더를 이동해 미접속 상태를 모의했다. 저장 장치 암호화와 실제 디스크 장애 복구도 시험하지 않았다.

실행: `node tests/server-operations.mjs`, `node tests/backend-hardening.mjs`, `node tests/smoke.mjs --features`, `tests/server-update.ps1 -Package <ZIP> -PublishedRoot <배포폴더> -FixtureParent <시험폴더>`. 반복 실행은 서로 다른 시험 폴더를 사용한다.

중간 시험 수정: PowerShell 7의 모듈 경로가 PowerShell 5 자식에 전달되는 시험 환경 문제를 분리했다. 시험용 첨부 삽입의 잘못된 열 이름을 실제 스키마에 맞췄고, 중복 종료 대기를 바로잡았다. Schannel 시험용 인증서는 인증서 저장소에 설치하지 않고 임시로 가져오는 방식으로 바꿨다. 백업 장치 재연결 후 졸업 재시도는 실제 정리 주기/재시작 경로로 검증했다. 업데이트 시험의 누락된 가상 연결 키를 추가했다. 이 실패들을 운영 환경의 검증 통과로 계산하지 않았다.

코드 검토 중 별도 백업 경로가 졸업 파기에서 빠지는 문제를 수정했다. 해당 장치에 접근하지 못하면 파기 완료로 기록하지 않도록 보완했다. 루프백 주소만으로 감시 요청을 인증하지 않으며 별도 키를 검사한다. 터널 커넥터의 방문자 주소는 명시한 루프백에서만 신뢰한다.

미확인: 실제 학교 Windows 버전/CPU/RAM, Hyper-V VM·망 분리, 실제 백업 장치·BitLocker·키 복구, UPS 정전·전원 복구, 실제 Cloudflare 계정/터널/인증서·학교 방화벽, Gmail 앱 비밀번호·실제 메일 수신, 별도 외부 감시 환경, 앱 관리자용 MFA, 스마트폰 실기기와 종료 상태 푸시. 개인 수신 주소는 로컬 전용 설정에만 저장하고 공개 저장소·ZIP에 포함하지 않았다. 실제 메일·방화벽 변경·작업 등록·Windows 정책 변경·릴리즈 발행은 수행하지 않았다.

재현 명령과 실제 설정 순서는 [운영 안내](server-setup-school-tunnel.md)에 있다. UPS·백업 장치가 없는 현 상태는 정식 운영 준비 완료가 아니다.
