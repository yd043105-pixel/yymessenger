# 회원가입 약관 반영 및 기본 보안 점검

2026-10-13. 프로그램 버전 1.0.0, 점검 기반 커밋 `ba707cd32d29954284bb9441059f956ebe17decf` 및 이번 작업 폴더의 미커밋 변경을 포함한다. 사용자가 공개 주소가 없다고 확인하여 공개 주소 검사는 실행하지 않았다. 이 자료는 개발 점검이며 운영 보안 인증·법률 적합성 판정·도름스 마크 발급 결과가 아니다.

**같은 날 후속 변경:** 사용자가 학생 재학 기간 보유·졸업 자동 탈퇴/파기와 교무실 문의처를 정한 뒤 문서는 draft.3으로 갱신하고 졸업 예약·두 서버 및 관리 백업의 파기 처리를 추가했다. 아래 도름스 원본은 그 추가 기능을 만들기 전 스냅샷의 결과이며 새 C# 기능을 검사한 결과로 사용하지 않는다. 후속 변경·시험 및 남은 범위는 [졸업 파기 안내](graduation-retention.md)에 별도로 기록했다.

## 실행 전에 확인한 도구

[고정 소스 커밋](https://github.com/shinnanchanguk/dorms-check/tree/91b40f6d0ea07d459ffce262ea2dc414a8adeb55)의 압축을 다시 내려받아 보관된 소스 96개 파일과 바이트 단위로 비교했다. 모두 일치했다. 압축 SHA-256은 `d3d733532e47457a7a604b1eb806aa7b1d39dafaa1a49b9228c6f26e942158da`, package.json 버전은 0.3.1이다. 압축 항목의 상위 경로 이동·절대 경로·심볼릭 링크를 거부하도록 확인했다. 외부 패키지의 AGENTS.md·SKILL.md는 검사 대상 자료이며 프로젝트 작업 지시로 채택하지 않았다.

`bin/dcheck.js`의 scan 분기와 정적 검사, 공개 응답 검사·런타임 탐색, HTTP 요청·결과 저장 코드를 확인했다.

- `scan --url`은 지정 주소의 헤더·본문·스크립트·노출 후보 경로 및 발견한 일부 Firebase/Supabase 주소를 읽기 요청으로 검사한다. 리다이렉트와 페이지에서 발견한 외부 주소를 따라갈 수 있다. 공개 검사 공통 시간 예산은 45초다.
- `scan --code-only`는 실행 폴더의 지원 확장자 파일을 검사한다. 결과·보고서·이력을 그 폴더의 `.dorms-check`에 저장한다.
- scan 분기에서 전역 훅 설치, 앱 코드 수정, 배포 차단 또는 도름스 서버에 검사 내용을 제출하는 동작은 발견하지 않았다. 패키지 전체에는 별도 `hooks status/uninstall`, `protect apply/restore` 등의 명령이 있으므로 모든 명령이 읽기 전용이라는 뜻은 아니다. 이번에는 scan만 실행했다.
- 루트 패키지에 preinstall/install/postinstall/prepare는 없다. npx는 패키지 및 npm 캐시에도 파일을 남기므로 프로젝트 안의 기존 캐시를 지정하고 설치 lifecycle은 `--ignore-scripts`로 비활성화했다. 이것은 실행 JavaScript의 격리나 전이 의존성 전체 감사가 아니다.

## 권고

1. 학교가 운영 주체·개인정보 담당자·문의처·법적 처리 근거·항목별 기간·위탁 및 대체 공지 수단을 확정하고 두 서버의 실제 처리 항목에 맞는 운영용 파일을 승인한다. 기존 정책과 재학생·졸업생·퇴직자·보호자 관계의 처리 기준을 함께 결정한다.
2. 학교가 홈페이지의 2년 재동의와 6개월 유예를 채택할지 먼저 결정한다. 이후 기존 회원 안내·재동의·철회/탈퇴·파기·백업 잔존 처리 기능을 구현하고 시험한다. 현재 30일 첨부 만료를 계정이나 본문 전체 파기로 설명하지 않는다.
3. 만 14세 미만 가입 대상이 있는지 확인하고, 동의를 근거로 처리한다면 법정대리인 동의 및 실제 확인 절차를 마련한다. 자녀 연결 코드를 입력했다는 사실을 이 확인의 대체 증거로 사용하지 않는다.
4. 실제 운영 시 HTTPS, 서버 계정/파일 권한, 악성파일 검사, 로그 최소화와 보유기간, 별도 백업 복원을 확인한다. 공개 주소가 준비되면 같은 고정 도구의 `scan --url` 결과를 추가하고 새 위험은 근거와 변경 내용을 제시한 뒤 처리한다.

## 확인하지 못한 내용

- 공개 URL 검사: 사용자 답변 “공개 주소 없음”에 따라 미실행. TLS 인증서·실제 공개 헤더·CORS·노출 파일·배포 환경은 미확인이다.
- 도름스의 지원 밖인 C# 전체 정적 보안 분석, 전이 의존성 전체 감사, 모든 과거 Git 이력 및 배포 비밀값. 로컬 소스 시험을 운영 침투시험으로 해석하지 않는다.
- 실제 Android/iOS 기기에서 새 전문 표시 및 접근성, 실제 OS 저장소·앱스토어 심사·FCM/APNs 알림. 이번 작업은 네이티브 클라이언트 소스를 변경하거나 해당 빌드를 다시 수행하지 않았다.
- 운영 서버의 악성파일 검사 실연동·VPN·방화벽·OS 패치·ACL·암호화·실제 정전/용량 부족 복구 및 학교의 개인정보/학운위 최종 결정.

미확인을 이유로 앱 구조나 호스팅을 바꾸지 않았다. 도름스 마크는 신청하지 않았으며 공개 주소 준비 후 앱 화면에서 별도로 신청한다.
