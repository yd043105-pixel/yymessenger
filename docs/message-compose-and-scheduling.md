# 메시지 작성·예약 전송·제출 현황

2026-10-13 · Windows PC 메신저 · 프로그램 버전 1.0.0. 실제 학교 계정에 메시지를 보내거나 릴리즈를 배포한 작업은 아니다.

## 작성 창

큰 새 메시지 제목/설명 영역과 왼쪽 전체 명부를 제거했다. 상단은 3줄 높이의 선택 수신자 영역이다. 선택한 사람만 이름·부서와 × 버튼으로 표시하며, 수신자가 많으면 영역 안에서 스크롤한다. ×로 제거하고 수신자 추가에서 검색·선택한다. 기존 조직도에서 선택한 사람도 여기에 반영된다.

나에게 전송을 누르면 수신자를 본인으로 바꾼다. 제목·본문을 작성하고 보내기를 누르면 본인의 받은함과 보낸함에 저장된다. 본인만을 대상으로 파일 제출 요청을 만들 수는 없다.

임시저장 버튼과 닫을 때 자동 저장 안내를 추가했다. 제목·본문·수신자·첨부 경로·제출/예약 입력을 저장하며 예약 시간이 아직 미완성이어도 이어서 작성할 수 있다. 새 파일은 Windows 현재 사용자 DPAPI로 암호화한다. 예전 같은 서버의 임시저장은 읽어 보호 형식으로 옮긴다. 실제로 전송했을지 모르는 요청은 같은 요청 번호로 재시도하며, 서버가 명확히 거부한 입력은 수정할 수 있다. 임시저장 삭제 버튼은 그대로 둔다. 사용자별 한 개 초안을 유지하는 기존 범위다.

## 예약 전송

예약 전송을 체크하고 한국 날짜·HH:mm 시각을 지정한 후 예약 저장을 누른다. 예약 목록에서 대기·전송 완료·취소·실패를 확인하고 본인의 대기 예약을 취소할 수 있다. 즉시 전송과 예약에 같은 요청 번호를 재사용할 수 없다. 예약을 지원하지 않는 구버전 서버에는 예약 요청을 보내기 전에 기능 경로를 확인하여 즉시 메시지로 오인 전송하지 않는다.

서버에 예약을 영속 저장하며 PC가 꺼져도 서버가 가동 중이면 보낸다. 운영 주기는 5초이고 서버가 꺼져 있었으면 다시 시작한 뒤 지난 예약을 처리한다. 정상 동작 시 예약 시각 이전에는 발송하지 않는다. 초 단위 정확한 도착 시각을 보장하는 타이머는 아니다.

예약 시점에 수신 대상을 확정하며 나중에 새 교직원이 생겼다고 대상을 확대하지 않는다. 발송 시 발신자 활성·초기 활성화 여부·전체 발송 권한과 수신자·첨부 사용 가능 여부를 다시 확인한다. 발신 계정 중지나 권한 상실·수신자 비활성화·첨부 만료·이미 지난 제출 마감 등은 실패로 남긴다. 서버 처리 오류는 재시도한다.

예약은 현재 이후 1년 이내이며 파일 제출 마감은 실제 예약 시각 이후로 지정해야 한다. 첨부가 예약 발송 전에 만료되면 등록을 거부한다. 예약에 묶인 첨부는 취소/완료 전까지 다른 전송·제출·삭제에 사용할 수 없고, 미게시 24시간 정리에서 제외한다. 원래 30일 만료는 연장하지 않는다. 대용량 한도와 저장 공간 보호 기준도 유지한다.

전송 후 확인 저장 전에 서버가 종료돼도 원래 요청 번호로 이미 저장한 메시지를 찾으므로 중복을 만들지 않는다. 백업 복원 시 대기 예약은 자동 취소하고 관리자가 일반 이용을 재개하기 전에 검토하도록 한다. 과거에 취소한 예약이 백업에서 살아나 자동 발송되지 않도록 한 조치다. 예약을 다시 사용하려면 내용을 확인하고 새로 등록한다.

## 파일 제출 현황

파일 제출 요청을 체크하고 마감일을 지정해 보내면 현황 창을 연다. 나중에는 보낸 요청의 제출 현황 보기 또는 메신저의 할 일·제출 → 파일 제출·수합에서 요청을 선택한다.

보낸 사람은 제출/전체·미제출·면제 수, 대상별 미제출·제출 완료·지각 제출을 확인하고 개별 파일이나 ZIP을 내려받을 수 있다. 받는 사람에게는 자신의 제출 상태만 보인다. 대상 면제와 요청 종료도 기존 권한 범위에서 제공한다. 예약 제출 요청은 예약을 저장한 순간이 아니라 메시지가 실제 발송된 때 만들어지므로 그 후 현황에 나타난다.

시운행 화면의 부서별 운영 계획 요청은 가상 대상 2명 중 1명 제출·1명 미제출이다. 실제 교직원이나 학생의 데이터가 아니다. 아주 작은 시운행 파일은 기존 KB 반올림 표시 때문에 0KB로 표시될 수 있다.

## 이름 우클릭

로그아웃 상태: 메시지 보내기, 파일 보내기, 채팅하기, 설문 보내기, 메시지 관리함, 사용자 정보보기, 즐겨찾기.

접속 중인 다른 사람: 위 메뉴에 원격 지원하기·원격 지원받기가 추가된다. 원격은 상대의 수락 절차를 거친다. SMS·메일·일정 생성·알림톡을 추가하지 않았다. 메뉴 화면은 기존 실제 네이티브 메뉴를 접속 상태별 가상 계정으로 촬영했다.

## 확인과 남은 점

Server·AnnouncementServer·Desktop 빌드 경고/오류 0. 실제 네이티브 작성·전송·임시저장/복원·자기 수신자 지정/× 삭제·제출 화면·예약 관련 사례와 기존 기능을 포함한 시운행이 통과했다. 원격의 실제 키보드 주입 1개는 제외했다. 100명 동시 로그인/전송·복원·권한·연결 서명 등 백엔드 점검 23개도 통과했다.

시험 중 C드라이브 여유 공간이 500MB 보호 기준보다 작아 업로드 507이 나왔다. 보호 기준을 낮추지 않고 `YY_TEST_DATA_ROOT`로 가상 시험 데이터를 D드라이브에서 생성했다. 원본 도름스 검사 범위나 호스팅을 바꾸는 설정이 아니다. 파일 만료를 8초로 줄인 가상 시험에서는 1시간 후 첨부 예약이 정상 거부되어, 가상 데이터의 기간과 개발 서버 시험 기간을 맞춰 다시 검사했다.

동시 전송 시험에서 한 차례 HTTP 500이 있었다. 당시 상세 서버 출력이 저장되지 않아 원인을 확정하지 못했다. 이후 실패 출력 저장을 추가하고 재시운행 및 100명 동시 점검은 통과했으며 같은 오류는 재현되지 않았다. 이를 원인까지 해결한 증거로 해석하지 않는다. 실제 운영 부하·실제 자정/예약 시각·서버 정전/물리 매체는 별도 확인 범위다.
