# Windows 교사용 메신저 설치 파일

배포 전 버전은 **1.0.0**이다. 설치 파일을 만들거나 GitHub 소스를 수정하는 작업은 릴리즈 공개 승인이 아니다.

## 교직원 PC 설치

릴리즈의 `yymessenger-버전-setup-win-x64.exe`를 실행한다. 한국어 설치 마법사에서 시작, 설치 위치, 시작 메뉴 폴더, 바탕화면 바로가기, 설치, 완료 순으로 진행한다. 기본 위치는 `%LOCALAPPDATA%\Programs\YeoyangSchoolMessenger`이며 현재 Windows 사용자에게 설치한다. 일반 설치에는 관리자 권한이 필요하지 않다.

.NET 런타임을 포함한다. Windows 10 빌드 19041 이상 또는 Windows 11의 x64 실행 환경을 대상으로 한다. ARM 기기의 x64 호환 실행은 별도 실기기 확인이 필요하다. 처음 실행하면 학교에서 안내한 **HTTPS 서버 주소**와 본인 계정으로 로그인한다. 실제 서버 주소를 설치 파일에 임의로 넣지 않는다. 자동 실행·자동 로그인은 기존 앱 설정에서 선택한다.

교사용 PC 설치 EXE와 서버 ZIP은 역할이 다르다. 서버의 HTTPS·접근망·악성코드 검사·데이터 경로 설정은 서버 패키지 운영 안내를 따른다. PC 설치는 서버를 생성하거나 방화벽을 변경하지 않는다.

## 이후 업데이트와 제거

메신저의 알림 영역 아이콘을 우클릭하고 **종료**한 다음 새 설치 EXE를 실행한다. 메인 창의 X는 알림 영역으로 숨기는 동작이므로 종료가 아니다. 실행 중인 앱을 강제로 종료하여 덮어쓰지 않는다.

같은 설치 식별자를 계속 사용하여 기존 경로에 덮어 설치한다. 더 오래된 숫자 버전의 설치 파일은 새 버전을 덮어쓰지 못한다. 설치·재설치·제거는 로그인 설정, 암호화 임시저장, 메시지 사본이 있는 `%LOCALAPPDATA%\SchoolMessenger`를 삭제하지 않는다. Windows 앱 목록 또는 시작 메뉴의 제거 바로가기로 프로그램을 제거할 수 있다. 자동 실행 항목은 제거하는 설치 경로를 정확히 가리킬 때만 삭제한다.

사용자 자료의 별도 파기는 앱의 개인정보 운영 정책에 따라 처리해야 한다. 프로그램 제거가 서버 계정 탈퇴나 서버 데이터 파기라는 뜻은 아니다.

## 제작

```powershell
# PC 설치 파일만 새로 빌드
./scripts/Build-Installer.ps1

# 서버/PC 전체 패키지를 검사한 뒤 해당 PC 배포본으로 설치 파일 제작
./scripts/Build.ps1 -HeadlessTests
./scripts/Build-Installer.ps1 -ClientDirectory ./artifacts/여양고-교무메신저/client
./tests/installer.ps1
```

`-OutputDirectory`로 결과 위치를 바꿀 수 있다. `-ClientDirectory`를 생략하면 최신 PC 소스를 Release로 게시한다. 지정한 경우 실행 파일의 제품 버전을 확인하며, DB·로그인 정보·암호화 사용자 자료·서버 실행 파일·비밀 설정이 입력에 있으면 중단한다. 디버그 심볼은 설치에 포함하지 않는다.

빌드 도구는 [공식 Inno Setup 배포본](https://jrsoftware.org/isdl.php)의 6.7.3을 고정하여 다운로드한다. SHA256 `9c73c3bae7ed48d44112a0f48e66742c00090bdb5bef71d9d3c056c66e97b732`와 Pyrsys B.V.의 유효한 서명을 확인한 뒤 도구를 설치한다. [공식 설치 지침](https://jrsoftware.org/ishelp/topic_setup_privilegesrequired.htm)에 따라 사용자 범위 설치를 사용한다. 도구의 서명과 학교 메신저 설치 파일의 서명은 별개다. **현재 생성하는 메신저 설치 파일에는 학교 코드 서명이 적용되지 않았다.** 실제 공개 배포 전에 서명 인증서와 Windows 게시자 표시를 준비·확인해야 한다.

결과는 설치 EXE와 `SHA256SUMS.txt`다. 확인할 때 아래 값과 해시 파일의 설치 EXE 항목을 비교한다.

```powershell
Get-FileHash ./artifacts/yymessenger-1.0.0-setup-win-x64.exe -Algorithm SHA256
```

## 검사와 릴리즈 연결

`tests/installer.ps1`은 실제 운영 설치와 다른 임시 설치 식별자·별도 자동 실행 항목·별도 시험 경로로 같은 설치 스크립트를 빌드한다. 파일 해시·네이티브 라이브러리·Windows 제거 항목·업데이트 시 자료 보존·구버전 차단·실행 중 차단·제거 시 경로 일치 항목만 정리하는 동작을 검사한다. `-RunNativeUi`는 설치된 실제 실행 파일로 가상 학교 서버의 로그인·메시지·파일·제출 등 WPF 검사를 추가한다. 학교의 실제 자료나 운영 가입 승인을 사용하지 않는다.

Windows CI에서 설치 검사를 실행한다. 실제 배포를 승인한 후 태그를 올리면 Release 작업이 검증한 서버 ZIP, PC 설치 EXE, 두 파일의 SHA256을 릴리즈 **초안**에 첨부한다. 태그 생성과 릴리즈 공개는 아직 실행하지 않는다. 앱이 스스로 업데이트를 내려받아 설치하는 기능은 포함하지 않는다.

2026-10-13 로컬 검사에서 설치된 PC 실행 파일로 WPF/API 73개 검사와 설치 수명주기 검사를 통과했다. 실제 Windows 키보드 주입 1개는 명시적으로 제외했다. 무인 실행에서 구버전 차단 대화상자가 확인을 기다리던 문제를 수정한 뒤 설치 검사 7개를 다시 통과했다. 설치 마법사 화면 자동 캡처 도구는 초기화 실패로 이용하지 못해, 대화형 마법사 전체의 육안 검토는 아직 확인 범위에 포함하지 않는다.

별도 이전 커밋 `78e8ed2`의 GitHub 검사에서 Windows·Android는 통과했지만 iOS 시뮬레이터의 회원가입 화면 대기가 실패했다. 해당 실패는 원인과 수정 완료를 확인하지 않았으며, Windows 설치 검사 결과를 iOS 통과로 제시하지 않는다.
