# 개인정보처리방침 검토안

여양메신저 학교 통합 소통 시스템 · 1.0.0 출시 전 · 2026-10-24

**미확정 검토용 자료다. 학교·운영자 정보와 실제 처리 구조를 확정하기 전 운영용 방침이나 에듀집 완성본으로 제출하지 않는다.** 학교별 서버 설치 방식이며 각 학교의 처리 주체·책임자·구성은 서로 다를 수 있다. 개발·기능 설명만으로 법령 준수를 인증하지 않는다.

## 1. 처리 주체와 연락처

운영·개인정보 처리 주체: [설치 학교가 확정]. 학교 개인정보 보호책임자 성명·직위·연락처: [학교가 확정]. 권리 행사 담당 창구: [학교가 확정]. 시행일·공개 경로: [학교가 확정]. 개발·유지관리 담당자와 학교 책임자는 구별한다.

여양고등학교에서 사용할 경우의 기존 문의처는 **여양고등학교 교무실 (061-689-5870)**이다. 이 창구를 모든 학교의 개인정보 보호책임자로 표시하지 않는다. 다른 학교는 관리자 프로그램에서 학교별 문서 초안을 만들고 해당 학교가 확정한 방침·약관을 서버별로 설정한다. 앱 내 정보와 PC 설정에서 적용된 운영 학교·문의처·전문을 확인한다.

## 3. 보유와 파기

학생의 구조화된 계정·연결·신청 정보는 **재학 기간** 보유하며 **졸업과 동시에 자동 탈퇴·파기**하도록 예약·처리한다. 보호자는 다른 재학 자녀가 있으면 유지하고 **마지막 재학 자녀가 졸업하면 함께 탈퇴·파기**한다. 관리되는 백업의 관련 정보도 기존 파기·복원 절차에 반영한다. 별도 법적 보관 의무가 있으면 그 근거·대상·기간·분리 보관을 학교가 특정해야 한다.

새 서버 첨부는 업로드 완료 시점부터 **30일** 보관한다. 공지 첨부는 JPG/PNG 이미지 한 장 200,000바이트, 공지당 최대 5장이다. 전달·재연동으로 원래 만료를 연장하지 않는다. 첨부 만료와 메시지 본문·동의 이력 파기는 다른 처리다.

교직원 업무 메시지는 현재 자동 기간 삭제가 없다. 단말의 업무 메시지 보관본, 교직원 계정, 로그·감사·오류/권리 접수·동의 증빙·백업별 구체 보유 기간과 파기 담당은 **학교 확정 필요**다. 이를 ‘영구 보관’이나 ‘모든 메시지가 서버에 남지 않음’으로 표시하지 않는다. 단말·메일·CSV 등 외부 사본은 서버에서 일괄 원격 삭제되지 않는다. 학교가 필요 기간과 안전한 삭제·접근 제한 절차를 확정한다.

## 4. 제공·위탁·외부 서비스

교내 업무 서버와 학생·학부모용 학교 소식 서버를 구별한다. 개인 업무 메시지·원격 화면을 학교 소식 서버에 일괄 복제하지 않는다. 게시가 허용된 공지·첨부·명부·수신 범위·시간표·상담·수강신청 등은 필요한 기능의 범위와 서비스 인증에 따라 연결한다. 학부모는 확인된 자녀와 허용된 자료만 조회한다.

실제 제3자 제공 및 위탁의 유무, 수신자/수탁자·업무·항목·근거·보유 기간·처리 위치·국외 이전·고지/필요 동의는 **학교별 운영 구성 확정 필요**다. 개발자 유지보수 접근, Cloudflare Tunnel, SMTP와 메일 수신처, 외부 백업·호스팅이 포함되는지 확인한다. 미구성 상태를 곧바로 ‘해당 없음’으로 적지 않는다.

오류 메일을 활성화하면 이름·발생 시각·접수번호·제품/버전·기능과 정제된 기술 진단이 설정한 수신처로 전달된다. 사용자가 요청한 개인 Gmail 수신 방식은 학교의 승인과 실제 처리 안내 검토 후 설정한다. 신고 원문·업무 메시지·첨부·비밀번호는 오류 메일에 넣지 않는다. 개인정보 권리 요청은 오류 메일과 개발용 내보내기에서 제외한다.

현재 외부 AI에 업무 메시지 본문을 보내지 않으며 운영형 FCM/APNs 백그라운드 푸시는 미구현이다. 해당 서비스가 추가되면 실제 정보 흐름과 처리 근거·공시를 갱신한다. 공급자 확인 없이 CSAP·ISMS-P·학교 심의 승인 등을 기재하지 않는다.

## 5. 안전조치

서버의 인증·역할·대상·관계 검사를 적용한다. 초기 교직원 비밀번호는 활성화 후 개인 비밀번호로 변경해야 업무 자료를 열 수 있다. CSRF 검증, 세션 폐기, 처리량·크기 제한, 허용된 서식·파일 검사·만료, 일반화된 오류와 개인정보 로그 정제, 접수 원문·회신의 Data Protection 암호화를 적용한다. Windows 자동 로그인은 DPAPI, 모바일은 SecureStorage를 사용한다.

저장장치 전체 암호화·단말/서버 관리자 접근 통제·백신·업데이트·백업 키 복구·인증서·방화벽·격리·UPS는 운영자가 실제 설정·시험한다. Data Protection이 DB 전체 암호화를 뜻하지 않으며, 학교 서버의 운영체제 관리자까지 접근할 수 없다는 보장은 하지 않는다. Cloudflare Tunnel은 익명화·단말 간 종단 암호화를 보장하는 기능으로 설명하지 않는다.

## 6. 권리 행사

PC **설정**, 앱 **내 정보**의 개인정보 권리 요청에서 열람·정정·삭제/탈퇴/동의 철회·처리정지를 접수한다. 로그인 계정에 연결하여 학교 서버에 보관하며, 본인 접수 상태와 학교 회신만 확인할 수 있다. 로그인 불가·접수 한도 초과·다른 도움이 필요한 경우 해당 학교 문의처로 요청한다.

학교는 본인 또는 적법한 대리인 확인 후 관련 법령에 따라 처리하고 처리 결과·지연 또는 제한 사유를 안내한다. 접수만으로 모든 정보가 즉시 파기되지는 않는다. 실제 담당자·처리 기한 관리·본인 확인·후속 처리·회신 책임은 **학교 확정 필요**다. 잘못된 자녀 연결·고유번호 유출 시 관계 해제·번호 재발급을 요청할 수 있다.

## 7. 아동 개인정보

현재 고등학교 대상 설계다. 실제 가입 대상에 만 14세 미만이 있는지는 학교가 확인한다. 동의에 근거하여 처리하는 만 14세 미만 아동은 법정대리인 동의와 실제 동의 여부 확인 절차를 마련해야 한다. 현재 자녀 고유번호 연결이나 학부모 임시회원 절차만으로 이를 대신하지 않는다. 해당 아동이 있으면 적절한 절차 마련 전 운영 가입을 진행하지 않는다. 생년월일·증명서 사본을 개발자가 임의로 추가 수집하지 않는다.

## 8. 방침 공개·변경·구제

확정 방침과 시행일·개정 이력·학교 책임자·권리 행사 창구·관계 기관 구제 안내는 학교가 확인해 공개한다. 재동의가 필요한 변경은 새 전문과 확인 기록으로 남기며 계속 이용했다는 이유로 동의 이력을 만들지 않는다. 이 검토안과 앱 가입 시 수집·이용 동의서는 서로 다른 문서이며 등록자 본인의 에듀집 개인정보 동의서와도 구별한다.
