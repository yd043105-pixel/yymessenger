# 상담 예약 연동

2026-10-14 · 배포 전 1.0.0

학교에서 제공한 최신 학년별 시각을 적용합니다. 3학년 4교시는 12:50–13:40이고 8교시는 17:00–17:50, 야간1은 19:00–19:50, 야간2는 20:00–20:50입니다. 개방할 담당 학급을 선택하면 그 학년의 교시 시각으로 표시합니다. 자세한 관리 절차는 [학교 시각·관리 안내](school-day-and-administration.md)를 참고하세요.

## 구성

`yd043105-pixel/yeoyangcounseling`의 학급별 시간 개방, 주간·야간 50분 상담, 예약 오픈 시각, 학생 1인 1예약, 취소·시간 변경 흐름을 기존 학교 앱과 메신저에 통합한다. 별도 웹 화면이나 Upstash 연결을 앱에 추가하지 않는다. 원본 비공개 저장소의 접근 토큰과 비밀번호는 복사하지 않는다.

참고한 원본은 `main`의 `60fcd6baac273266b3a107a2a10125e16b3bc04f`이다. 원본 코드·실제 DB·예약·배포 설정을 변경하지 않았다.

학생·학부모용 공지 서버가 상담 시간과 예약의 유일한 원본이다. PC 메신저와 교사용 앱은 교내 서버를 통해 기존 HMAC 인증 연결로 요청한다. 교내 서버가 로그인한 교사의 연결된 외부 계정을 결정하며 클라이언트가 교사 계정을 지정할 수 없다. 교내 서버로 들어오는 외부 연결은 추가하지 않는다. 외부 서버가 끊겼을 때 변경은 성공으로 표시하거나 예약 대기열에 넣지 않는다.

## 사용 흐름

- 학교 소식 관리자에게 교사의 교내 계정과 담당 학급을 연결한다. 기존 공지 발송 계정 연결을 재사용한다.
- 교사는 날짜, 담당 학급, 상담 시간대를 선택하여 즉시 또는 지정 시각에 예약을 개방한다. 기본적으로 모든 시간은 닫혀 있다. 본인 상담 시간의 신청자만 조회하며 이미 예약된 시간은 신청 취소 후 닫는다.
- 학생은 승인된 본인 계정, 학부모는 연결된 재학 자녀를 선택해 열린 상담을 신청한다. 다른 신청자의 이름·학번은 공개하지 않는다. 신청 즉시 예약을 확정하며 별도 예약 비밀번호를 사용하지 않는다.
- 학생별 미래 상담은 학생과 모든 연결 보호자를 합쳐 한 건만 허용한다. 같은 시간의 동시 신청과 교사의 시간 중복은 DB 트랜잭션 및 유일 인덱스로 방지한다. 시간 변경은 새 자리를 확보하고 기존 자리를 해제하는 하나의 트랜잭션으로 처리한다.
- 신청자 및 연결 보호자는 자녀의 예약을 취소할 수 있다. 교사는 본인 예약을 취소할 수 있다. 이미 시작된 상담은 신청·변경·취소하지 않는다. 담당 학급이나 보호자 연결이 바뀌면 매 요청에서 권한을 다시 검사한다.
- 조회·개방·예약은 날짜 범위와 건수를 제한한다. 자동 새로고침이나 새로운 상시 작업은 추가하지 않는다. 앱에서 새로고침하여 최신 예약을 확인한다.

## 개인정보와 운영 전환

상담 내용, 전화번호, 별도 비밀번호는 저장하지 않고 계정 식별자와 예약 시각만 저장한다. 과거 상담은 6개월 경과 후 정리하고 졸업 탈퇴 때 대상 학생·보호자 예약은 관리되는 DB 백업까지 기존 파기 절차에 포함한다. 기존 약관 초안은 상담 예약의 처리 목적·항목을 포함해 학교 검토를 거쳐 확정한다.

원래 상담 웹사이트와 이 앱은 같은 예약 DB를 공유하지 않는다. 기존 운영 중인 예약의 자동 이관·삭제는 수행하지 않는다. 같은 교사의 같은 시간대를 두 시스템에서 동시에 개방하면 중복 예약될 수 있으므로 기존 예약을 대조하고 새 앱으로 전환할 날짜를 정한다. 기존 화면에 포함된 DB 접근 토큰은 제공업체에서 교체하고 이전 토큰을 폐기해야 한다. 저장소를 비공개로 두는 것만으로 이미 노출된 자격 증명이 무효화되지는 않는다.

## 검증

`node tests/counseling.mjs`는 실제 로컬 HTTP 서버와 가상 계정으로 상담 예약을 검사한다. `YY_COUNSELING_UI=1`로 실행하면 별도 시험 계정·설정 경로를 사용하는 네이티브 Windows 화면 검사도 포함한다. 학교 운영 계정이나 실제 기존 예약을 사용하지 않는다.
