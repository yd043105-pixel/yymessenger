# 서버·컴퓨터·휴대폰 실행 안내

2026-10-15 · 배포 전 1.0.0.

현재 설치와 출시 순서는 [Windows·Android·iOS 운영 안내](platform-deployment-guide.md)를 따른다. 교직원용 앱과 학생·학부모용 앱은 각각 별도 제품이며 Windows 메신저도 별도 설치 프로그램이다. 통신할 HTTPS 서버 주소를 입력하는 것은 웹앱을 사용한다는 뜻이 아니다.

서버 설치·학교 회선·Cloudflare·UPS·백업·장애 알림은 [학교 서버 운영 안내](server-setup-school-tunnel.md), Windows 마법사 설치와 갱신은 [Windows 설치 안내](windows-installer.md), 실제 iPhone 서명·시험은 [iOS 운영 안내](ios-operations.md)를 참고한다.

현재 APK는 시운행용이고 iOS 실제 배포 서명·스토어 공개는 완료되지 않았다. 공개 HTTPS·실기기·푸시·앱 내 탈퇴 절차 등 미확인·미완료 범위는 새 운영 안내에 명시했다. 이전의 통합 모바일 모드·일반 공지 파일 제한·폴더 분리만으로 운영 가능하다는 설명을 현재 운영 지침으로 사용하지 않는다.
