# 서버·컴퓨터·휴대폰 앱 실행 안내

2026-10-09 소스 기준, 배포 전 버전 1.0.0. 아래 실제 운영 예시의 도메인·인증서 지문·네트워크 대역은 학교 값으로 바꾼다. 이 문서를 작성하면서 서버 공개·방화벽 설정·자동 시작 등록을 수행하지 않았다.

## 현재 상태와 목표

2026-10-13 갱신: 가입과 교직원 활성화의 약관·개인정보 안내는 앱 내부 화면에서 처리한다. 기본 초안으로 Production 가입·최초 활성화는 진행할 수 없으며 [학교가 확정할 정책 파일 설정](registration-policy-operations.md)이 필요하다. PC 관리 메뉴는 네이티브 창으로 전환했고 교사/가족 앱도 별도 설치 ID로 빌드한다. [새 계정·학사일정·예약·분반 운영](teacher-office-operations.md)을 함께 따른다.

일반 사용자는 설치한 Windows 프로그램과 Android/iOS 앱에서 업무를 처리하는 것이 목표다. 앱도 통신할 HTTPS 서버 주소가 필요하며, 그것이 브라우저 사용을 뜻하지는 않는다.

기존 웹 경로는 소스에 남아 있다. PC의 관리자 메뉴는 설치 프로그램의 관리 창을 열며, 학생·보호자 가입·자녀 연결도 앱 내부에서 처리한다. 별도 가족 앱은 학생/학부모 계정만 허용하고 교사 앱은 교직원 서버를 사용한다. 공통 개발 검증 앱에는 이전 접속 모드가 유지된다.

교사용 앱은 `kr.school.yeoyang.teacher`, 학생/보호자용 앱은 `kr.school.yeoyang.family`다. 빌드와 스토어 출시를 구분한다. 교사용 휴대폰 기능은 메시지·첨부 조회, 시간표, 제한 공지, 학사일정과 특별실 예약이며 PC의 모든 채팅·설문·제출 화면을 그대로 제공하는 것은 아니다.

| 구분 | 실행할 프로그램 | 연결 대상 | 현재 제공하는 핵심 기능 |
| --- | --- | --- | --- |
| 학교 서버 컴퓨터 | `server\SchoolMessenger.Server.exe` | 교내망에서 HTTPS 7443 | 교직원 계정·쪽지·채팅·설문·할 일·제출·시간표·원격 연결 관리 |
| 별도 외부 공지 서버 | `announcement-server\SchoolMessenger.AnnouncementServer.exe` | 학교가 소유한 공개 HTTPS 주소 | 공지·전용 첨부·학생/보호자 계정·학급/자녀 관계·시간표 |
| 교사 사용자 컴퓨터 | `client\SchoolMessenger.exe` | 학교 서버 HTTPS 주소 | 교무 메신저 전체 기능, 외부 공지 작성·발송 현황, 시간표 업로드 |
| 교사용 휴대폰 | 현재 같은 MAUI 앱의 교직원/학교 소식 모드 | 업무는 교내망/VPN, 외부 공지는 공개 서버 | 업무 메시지 조회·공지 작성·열람·시간표. PC 원격 제어는 PC에서 사용 |
| 학생·보호자 휴대폰 | 현재 같은 MAUI 앱의 학교 소식 모드 | 공개 공지 서버 HTTPS 주소 | 가입·자녀 연결·대상 공지/첨부·시간표 |

외부 서버는 기존 설계대로 교직원 서버와 다른 호스트·DB·데이터 폴더를 사용한다. 앱 전용이라는 이유로 이 분리를 합치지 않는다. 인터넷에는 외부 공지 서버만 공개한다. 교직원 서버가 공지 서버에 발신 연결하며 개인 업무 쪽지·채팅·제출 파일은 외부 공지 서버로 복사하지 않는다.

## 1. 서버 컴퓨터

### 패키지 준비

현재 로컬 배포 ZIP/APK는 최신 회원가입 소스보다 오래된 빌드일 수 있다. 개발 폴더에서 최신 소스를 검증·빌드하여 생성한 패키지를 사용한다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build.ps1 -HeadlessTests -Version 1.0.0
```

이 명령은 개발 PC에서 .NET SDK로 빌드·시험·Windows 패키지를 생성한다. 운영 서버에서 매번 실행할 명령은 아니다. 생성한 `artifacts\여양고-교무메신저` 또는 배포 ZIP을 운영 위치에 복사한다. 서버 실행 스크립트는 **이 배포 폴더의 scripts**에서 실행한다. 저장소 루트에는 스크립트가 찾는 `server` 실행 파일 폴더가 없으므로 저장소에서 바로 시작하면 실패한다.

### 학교 교직원 서버

1. 학교의 고정 서버 이름/IP, 교직원망 CIDR, 개인키가 있는 신뢰되는 HTTPS 인증서를 준비한다. 인증서는 Windows 로컬 컴퓨터/개인 저장소에 설치하고 운영 계정에 개인키 읽기 권한을 준다.
2. 학교 서버용 별도 데이터·백업 폴더를 마련하고 운영 계정만 읽고 쓰도록 제한한다. 기존 폴더를 바꾸면 새 서버로 초기화되므로 업데이트에도 같은 경로를 유지한다.
3. Windows Defender의 검사 실행 권한을 확인한다. 운영 모드에서 검사 실패·시간 초과 시 첨부를 거부한다.
4. 배포 폴더로 이동한 후 시작한다. 최초 admin 비밀번호 12~128자는 스크립트의 숨김 입력으로 설정한다.

```powershell
Set-Location 'D:\YyMessenger'
.\scripts\Start-Server.ps1 `
  -CertificateThumbprint '학교서버인증서지문' `
  -AllowedNetworks '192.168.10.0/24,192.168.20.0/24' `
  -DataDirectory 'D:\YyMessengerData\school' `
  -BackupDirectory 'E:\YyMessengerBackups\school' `
  -Port 7443
```

서버 창을 닫거나 Ctrl+C를 누르면 서비스가 중단된다. 절전·최대 절전으로 서버가 멈추지 않도록 한다. 방화벽 7443은 실제 교직원망만 허용하며 인터넷 포트 포워딩 대상에 넣지 않는다. 같은 학교에 여러 VLAN/Wi-Fi 대역이 있으면 실제 허용 범위를 정보담당자가 확인한다.

### 별도 외부 공지 서버

학교 밖 휴대폰 접속에는 학교가 관리하는 공개 DNS·인증서·인터넷 접근 가능한 공지 서버가 필요하다. 아직 실제 주소가 제공되지 않아 현재 소스가 인터넷에서 서비스되고 있는 것은 아니다.

```powershell
Set-Location 'D:\YyAnnouncements'
.\scripts\Start-AnnouncementServer.ps1 `
  -CertificateThumbprint '공지서버인증서지문' `
  -PublicHost '실제학교공지도메인' `
  -DataDirectory 'D:\YyAnnouncementData' `
  -BackupDirectory 'E:\YyMessengerBackups\announcements' `
  -Port 443
```

첫 실행은 외부 서버의 독립된 admin 비밀번호와 전용 연결 키를 숨김 입력으로 받는다. 연결 키는 암호학적으로 생성한 32자 이상의 비밀값을 사용한다. 키를 앱·URL·GitHub·공유 문서에 넣지 않는다. 스크립트의 기본 포트는 8443이며 위 예시에서는 명시적으로 443을 선택했다.

외부 서버에는 `Portal__BridgeKey`, 교직원 서버에는 `Announcements__BridgeKey`를 동일하게 설정한다. 교직원 서버 실행 환경에 `Announcements__Address=https://실제학교공지도메인`도 지정한다. 키 입력·보관은 제한된 운영 계정과 비밀 관리 절차로 처리한다. 내장 스크립트는 장기 비밀 저장소나 자동 연결 키 배포를 만들지 않는다.

현재 공지 서버는 직접 HTTPS를 제공한다. 임의 프록시 설정으로 바꾸거나 교직원 서버를 공개할 필요가 없다. 인증서 갱신 후 새 인증서 지문을 확인하고 재시작한다.

### 자동 시작과 운영 확인

두 서버는 각각 전용 계정의 Windows 작업 스케줄러로 시작할 수 있다. 첫 정상 기동·접속·백신 확인 뒤 등록한다. ‘시작 시’, ‘사용자 로그온 여부와 관계없이 실행’, ‘실패 후 다시 시작’을 설정하고 중복 인스턴스는 막는다. 자동 시작 시에는 숨김 입력을 받을 수 없으므로 운영 설정과 연결 키를 미리 보호된 실행 환경에 제공해야 한다. 대화형 첫 초기화를 그대로 작업 스케줄러에 넣지 않는다.

| 서버 | 실행 파일 | 시작 위치 | 필요한 운영 설정 |
| --- | --- | --- | --- |
| 교직원 | `D:\YyMessenger\server\SchoolMessenger.Server.exe` | 같은 server 폴더 | `ASPNETCORE_ENVIRONMENT=Production`, School의 데이터/백업/인증서/허용망, Announcements의 주소/키 |
| 공지 | `D:\YyAnnouncements\announcement-server\SchoolMessenger.AnnouncementServer.exe` | 같은 announcement-server 폴더 | `ASPNETCORE_ENVIRONMENT=Production`, Portal의 데이터/백업/인증서/AllowedHosts/연결 키 |

각 실행 인수에는 `--urls https://0.0.0.0:7443` 또는 `--urls https://0.0.0.0:443`을 지정한다. 비밀 키를 작업 인수나 평문 문서에 적지 않는다. 키·설정은 해당 운영 계정과 시스템 관리자만 접근하도록 학교의 관리 방식에 맞춘다. 스크립트만 실행했을 때 자동 시작이 등록되지는 않는다.

부팅 후 `/health` 응답, 관리자 연결 상태, 계정 승인, 공지 발송→가족 열람, 30일 파일 만료·백업 생성을 확인한다. health 응답은 정상 프로세스 확인이며 모든 기능의 정상 여부를 보장하지 않는다. 외부 서버만 중단되면 교내 업무는 계속되고 공지는 대기한다. 교내 서버가 장시간 중단되면 교사의 외부 로그인/발송은 제한되지만 가족은 이미 게시된 허용 공지를 읽을 수 있다.

백업 DB·암호화 키·서버 설정의 복구를 함께 관리한다. 첨부 내용은 현재 백업하지 않는다. 백업 경로 지정은 Windows 폴더 ACL이나 디스크 암호화를 자동 적용하지 않는다.

## 2. 사용자 컴퓨터

현재는 Windows x64 ZIP 배포다. 원하는 고정 폴더에 client 전체를 복사하고 `SchoolMessenger.exe`를 실행한다. 설치 마법사 EXE와 자동 업데이트는 아직 없다. exe 한 개만 떼어 복사하지 않는다.

1. `https://학교서버이름:7443`을 입력한다. `localhost`는 자기 PC이므로 다른 교사의 PC에서는 학교 서버 주소를 사용한다.
2. ‘계정 신청’ 후 최초 학교 관리자 승인으로 로그인한다.
3. 필요하면 Windows 로그인 시 자동 실행·자동 로그인을 켠다. Windows 계정 로그인은 별도로 필요하다.
4. 학교 공지에서 수신 학급/역할을 선택해 발송한다. 작성한 개인 쪽지를 자동으로 학부모에게 공개하지 않는다.
5. 수업 담당 권한이 있는 교사는 시간표에서 엑셀을 미리보고 게시한다. 게시 대기·외부 전달 상태를 확인한다.

원격 지원은 두 PC가 화면·입력을 직접 주고받는다. 서버는 연결 권한만 관리한다. 필요한 PC 간 방화벽 규칙은 정보담당자가 `Configure-RemoteFirewall.ps1`을 `-WhatIf`로 검토한 후 적용한다. 사용자 프로그램 설치만으로 방화벽이 변경되지는 않는다. 학교 밖 업무 접근에는 학교 승인 VPN이 필요하다.

## 3. 교사용 휴대폰 앱

현재 시운행 앱을 설치한 후 ‘교직원 교무실’을 선택하고 학교 서버 HTTPS 주소로 접속한다. 교내 Wi-Fi 또는 승인 VPN과 서버 인증서 신뢰가 필요하다. PC에서 승인된 교직원 계정을 사용한다. 받은/보낸/미확인 메시지, 공지 작성과 발송 현황, 개인 수업 시간표를 확인한다.

‘학교 소식’ 모드에서 공개 서버 주소를 사용할 수도 있다. 이 모드의 교사 계정은 외부 관리자에게 PC ‘학교 공지’ 창의 교내 계정 번호를 알려 별도로 연결하고 담당 학급을 지정해야 한다. 교내 계정과 공지 계정은 서로 다른 서버의 계정이므로 동일 비밀번호·자동 연동 로그인을 가정하지 않는다.

앱을 종료한 상태에서 알림이 도착하는 푸시는 아직 없다. 현재는 앱을 열어 조회/새로고침해서 확인한다. Android/iOS 소스와 CI 빌드는 있지만 실제 기기 검증·최신 설치 파일·스토어 서명과 배포 절차는 별도 준비가 필요하다.

## 4. 학생·학부모용 휴대폰 앱

현재 같은 앱의 ‘학교 소식’ 모드에서 학교가 안내한 공개 HTTPS 주소를 입력한다. 내부 서버 7443 주소를 안내하지 않는다.

- 학생: 이름·아이디·비밀번호·학급·번호로 개별 가입한다. 학교가 명부 대조 후 승인하면 로그인하고 설정에서 본인 고유번호를 확인한다.
- 학부모: 자기 계정으로 개별 가입해 임시회원으로 로그인한다. 설정에서 자녀 고유번호를 입력하면 즉시 정회원이 된다. 재학 중인 자녀가 여러 명이면 각각 추가한다.
- 로그인한 학생은 자기 학급, 학부모는 연결된 자녀 학급에 허용된 소식·시간표만 조회한다. 새로운 자녀 연결은 이전 비공개 공지 수신자를 소급 확대하지 않는다.
- 일반 학생·보호자는 앱 내부에서 이용한다. 관리자 승인·학급 등록·고유번호·보호자 관계도 PC의 별도 학교 소식 관리 창에서 처리할 수 있다.

개인 수강 명부를 받기 전에는 학생별 선택과목까지 개인화한 시간표가 아니라 학급 시간표를 제공한다. 급식 조회와 닫힌 앱 푸시는 미구현이다. 첨부는 서버 보관 기한 후 만료되며 이미 휴대폰에 저장·공유한 사본은 자동으로 회수되지 않는다.
