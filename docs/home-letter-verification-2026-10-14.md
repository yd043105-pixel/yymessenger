# 공지 이미지 변경 검증 — 2026-10-14

버전은 1.0.0이다. 아래 첫 표는 가정통신문 제한을 먼저 구현했을 때의 검사 결과이며, 이후 전체 공지로 확대한 검사는 문서 끝에 별도로 기록한다. 실제 학교 자료·학생 계정·메일 인증·공개 서버를 사용하지 않았다. 설치파일은 로컬에서 제작했으며 코드 서명, 스토어 공개, 학교 서버 배포는 하지 않았다.

| 검사 | 통과 수 |
|---|---:|
| 공지·권한·이미지 제한 (`announcements.mjs`) | 23 |
| 교내 서버→공지 서버 연동 (`announcement-bridge.mjs`) | 9 |
| 졸업 정보 파기 (`graduation.mjs`) | 10 |
| 서버 운영·백업·터널 원본 보호 (`server-operations.mjs`) | 25 |
| 백엔드 동시 처리·복구·권한 (`backend-hardening.mjs`) | 23 |
| 기존 메신저·채팅·설문·제출·예약 (`smoke.mjs --features`) | 69 |
| 실제 설치파일의 설치·업데이트·제거 | 7 |
| 실제 Release 서버 묶음의 업데이트·데이터 보존·로그인 | 2 |

서버 기능 159개, 설치·패키지 9개가 통과했다. 두 서버 및 PC 프로그램의 Debug/Release 빌드, 교사용과 학생·학부모용 Android Debug APK 빌드가 경고·오류 없이 완료되었다. 실제 Windows 설치 마법사의 화면 조작을 이번 검사에 포함하지 않았다.

이미지 검사는 JPG/PNG 제한, 확장자 위장 거부, 500,000바이트 허용, 500,001바이트 거부, 과도한 해상도 거부, 일반 첨부로 업로드한 뒤 가정통신문에 붙이는 우회 거부를 포함한다. 대상이 아닌 학생과 미로그인 사용자는 이미지를 받을 수 없다. `inline`·이미지 MIME·`no-store`·`nosniff`, 다운로드 경로 차단, 회수·만료 후 접근 차단, 원본 보관 기한 유지와 재시도도 확인했다.

Android 36 에뮬레이터와 가상 자료로 학생·학부모용 앱의 인증된 JPG 표시 상태·저장/공유 버튼 제거와 확대 읽기 2개를 확인했다. 최종 교사용 APK의 기본 유형 안내, 실제 PNG 선택·초안 보존·업로드, 네이티브 발송 후 양쪽 서버 게시 확인 3개가 통과했다. 총 5개 조작 항목을 별도 실행으로 확인했으며 교사 최종 결과는 `artifacts/home-letter-mobile-test-results.json`에 기록한다. 이미지 표시 코드는 파일 공유 경로를 사용하지 않는다. 기존 Android `FLAG_SECURE`를 유지하여 화면 캡처는 검게 나온다. 캡처 이미지로 실제 픽셀 품질을 검증했다고 주장하지 않는다.

초기 검사 중 발생한 문제와 처리:

- Android AAPT2가 한글 경로에서 실패하여 기존 ASCII 경로 빌드 방식을 사용했다. C 드라이브 공간 부족 시 업로드가 507로 거부되었으며 보호 제한을 낮추지 않았다. 새로 생성한 임시 빌드 자료와 가상 검사 데이터를 D 드라이브로 옮겼다.
- 졸업 검사에서 기본 백업 폴더의 일부 파일명 누락이 재현되었다. 기본 세 백업 폴더에서는 모든 DB를 검사하고 별도 장치에서는 해당 서버 역할의 파일명만 검사하도록 수정했다. 졸업 10개와 운영 25개가 이후 통과했다.
- Android 자동 조작의 일시적인 접근성 트리 준비 지연, 이미지 선택기의 파일명을 포함한 접근성 설명, 새 유형 Picker로 달라진 입력 필드 순서를 검사 코드에 반영했다. 앱의 보안 설정을 해제하지 않았다.
- 많은 발송 내역 뒤에 선택 파일명이 표시되는 기존 불편을 확인하여 첨부 목록을 보내기 버튼 앞의 별도 영역으로 옮겼다. 최종 APK로 선택·업로드·발송을 다시 검사했다.

미확인: 이번 변경의 Mac/iOS 빌드와 실제 iPhone·Android 기기, 학교에서 사용하는 실제 가정통신문의 500KB 압축 후 가독성, 운영 학교 서버·Cloudflare 설정. 자동 이미지 압축·변환은 제공하지 않는다. 중요 안내는 공지 텍스트 본문에도 적어 화면 낭독기 사용자를 지원한다. [사용·변경 안내](home-letter-images.md)를 따른다.

## 학생·학부모용 모든 공지로 범위 확대

사용자가 일반 공지도 같은 제한으로 확정하여 공지 유형과 무관하게 JPG·PNG, 한 장당 500,000바이트, 최대 10장으로 통일했다. 유형 생략, 일반 공지 유형, 이전 미게시 첨부에서도 업로드와 게시 검사를 적용한다. 공지 다운로드 경로는 모두 닫고, 앱은 모든 공지 첨부를 바로 표시한다. 이전 문서·초과 용량 첨부는 표시하지 않으며 본문과 원본 데이터는 자동 삭제하지 않는다.

이번 확대 후 다시 실행한 서버 검사는 공지 24개와 연동 10개, 총 34개가 통과했다. 일반 공지와 가정통신문 모두 비이미지·위장 파일·500,001바이트를 거부하며, 일반 공지에서도 정확히 500,000바이트를 허용한다. 이전 문서 첨부를 가장한 DB 검증 자료는 게시와 열람에서 차단됐다. 교직원 비공개 파일은 기존 내부 경로로 올라가고 외부 공지에 재사용할 수 없다.

확대 적용 후 기존 메신저 기능 69개, 최종 설치파일의 설치·업데이트·제거 7개, 최종 Release 서버 묶음의 업데이트·데이터 보존·로그인 2개를 다시 실행해 통과했다. 실제 설치 마법사의 화면 조작은 검사하지 않았다. 서버·PC 및 별도 Android 두 앱을 다시 제작했으며 경고와 오류는 없었다. 버전과 앱 버전 코드는 변경하지 않았다.

최종 Android 시운행에서는 일반 공지 JPG의 인증된 바로 표시·저장/공유 버튼 제거, 확대 읽기, 교사용 기본 유형 안내, 일반 공지로 바꾼 뒤 네이티브 PNG 선택·초안 보존·업로드, 교내 서버를 통한 일반 공지 게시 확인까지 5개를 한 실행으로 통과했다. 최종 결과는 `artifacts/home-letter-mobile-test-results.json`에 기록한다. Android 보안 캡처 차단을 유지하여 화면 픽셀 품질을 캡처로 확인하지는 않았다. iOS 소스와 검증용 이미지 자료는 수정했으나 이번 변경의 Mac 빌드·실제 기기 검증은 하지 않았다.
