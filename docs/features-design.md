# 채팅·설문·원격 지원 추가 설계

기존 개인 쪽지·첨부파일·읽음 확인·계정 승인·자동 로그인은 유지하고, 추가 기능은 채팅·설문·원격 지원으로 한정한다. SMS·메일·일정 생성·학부모 알림톡은 이번 범위에 포함하지 않는다. 작은 조직도와 승인받은 남색·파란색 디자인을 유지한다.

## 구현 방식

기존 ASP.NET Core 서버, SQLite, SignalR, WPF 앱을 확장한다. 새 서버나 외부 서비스, 추가 제품 라이선스 없이 학교 내부 HTTPS 연결로 운영한다. 작업 순서는 채팅, 설문, 원격 지원이다. 기능마다 서버 권한 검사와 실제 데스크톱 화면을 함께 완성한 뒤 배포 파일을 갱신한다.

외부 원격지원 도구를 실행하는 방식은 외부 프로그램 운영에 의존한다. Windows 원격 데스크톱을 이용하는 방식은 별도의 Windows 계정·접속 정책이 필요하다. 원격 지원은 추가 승인된 [PC 직접 연결 설계](remote-direct-design.md)에 따라 학교 서버에서 요청·권한을 관리하고 두 PC 사이에 TLS로 화면·입력을 직접 전송한다. 첫 버전은 문서·설정 문제를 함께 해결하는 용도이며 고화질 영상 재생용이 아니다.

## 채팅

- 1:1 대화와 여러 교직원을 선택한 단체 대화방을 제공한다. 조직도 우클릭에 ‘채팅하기’, 왼쪽 메뉴에 ‘채팅’을 추가한다. 접속하지 않은 교직원도 대화에 참여할 수 있으며 다음 로그인 때 기록을 확인한다.
- 별도 대화 창에서 대화방 목록, 참여자, 시간순 기록, 입력창을 제공한다. 방 이름을 정할 수 있다. 첫 버전은 생성 시 참여자를 확정한다.
- 텍스트와 첨부파일을 보낼 수 있다. 기존 파일 검사·용량 제한·30일 만료를 동일하게 적용한다. 파일이 만료되어도 대화 기록과 만료 안내는 남는다.
- 대화는 DB 저장을 먼저 완료하고 알림을 보낸다. 재전송 요청 번호로 중복을 방지한다. 재연결 시 놓친 대화를 다시 조회한다. 기록은 나누어 불러오고 읽지 않은 대화 수를 표시한다.
- 해당 방의 참여자만 기록·첨부파일을 조회할 수 있다. 일반 관리자 권한만으로 타인의 대화를 조회할 수 없다.

## 설문

- 왼쪽 메뉴에 ‘설문’, 조직도 우클릭에 ‘설문 보내기’를 추가한다. 교직원·부서 단위로 대상을 선택하고 전체 교직원 발송은 기존 전체 발송 권한을 따른다.
- 제목·설명·마감 시각과 여러 문항을 입력한다. 문항은 단일 선택 객관식과 주관식이며 필수 여부를 정할 수 있다.
- 첫 버전은 기명 설문이다. 대상자에게 새 설문 알림을 보내며, 미응답·응답 완료 상태를 보여준다. 마감 전에는 응답을 수정할 수 있다.
- 작성자는 응답 인원, 문항별 집계, 응답자별 답변을 보고 CSV로 내보낼 수 있다. 대상자는 자기 응답만 조회한다. 대상 외 교직원은 설문과 결과에 접근하지 못한다.
- 마감되거나 작성자가 종료하면 새 응답과 수정을 차단한다. 응답 여부는 남기고, 작성자가 다른 사람의 답변을 대신 작성할 수 없게 한다.

## 원격 지원

- 접속 중인 교직원을 우클릭해 지원을 요청한다. ‘지원하기’는 상대 화면을 보는 요청, ‘지원받기’는 자기 화면을 공유하는 요청이다. 실제 화면 공유자에게 요청자 이름과 공유 범위를 표시하고 수락·거절을 받는다. 자동 수락은 없다.
- 기본 설계는 화면 보기와 마우스·키보드 제어를 제공하는 방식이다. 공유자는 수락할 때 ‘화면만 공유’ 또는 ‘제어도 허용’을 선택하며, 지원 도중에도 제어 허용을 해제할 수 있다.
- 승인된 두 PC만 암호화된 직접 연결로 화면과 입력을 주고받는다. 서버는 연결 정보·권한·종료만 관리하며 화면·입력 중계와 디스크 저장·녹화를 하지 않는다. 동시 지원은 PC당 한 건으로 제한한다.
- 화면 공유자에게 연결 상태와 종료 버튼을 계속 표시한다. 어느 쪽이든 종료하거나 로그아웃·연결 끊김·계정 비활성화가 발생하면 화면 전송과 제어를 중단한다. 끊긴 원격 지원은 자동 복원하지 않는다.
- 첫 버전은 주 모니터 화면을 압축하여 초당 최대 2회 전송한다. 요청·수락은 짧은 유효시간을 두고, 활성 지원은 최대 30분 뒤 종료한다. 크기 제한과 전송 속도 제한을 적용한다.
- 제어를 선택하면 일반 Windows 화면의 클릭·스크롤·키보드 입력을 지원한다. 잠금 화면, UAC 보안 화면, 관리자 권한으로 실행한 프로그램은 첫 버전 제어 대상에서 제외한다. 관련 제한은 지원 화면에 표시한다.

## 데이터와 확인 기준

새 테이블은 기존 DB를 지우지 않고 추가한다. 채팅 첨부도 기존 파일 정리와 다운로드 권한 검사를 함께 확장한다. 설문과 채팅 본문은 기존 쪽지와 같이 자동 삭제하지 않는다.

서버 검증은 방·설문·원격 세션의 타인 접근 차단, 중복 채팅 방지, 오프라인 기록 복원, 파일 만료, 설문 마감·수정·집계, 수락 전 원격 화면·입력 차단, 종료 후 차단, 로그아웃과 연결 끊김에 따른 종료를 포함한다. WPF 검증은 새 창을 열고 채팅 전송·설문 작성과 응답·원격 요청 상태를 실제로 조작한다. 실제 원격 화면 제어의 최종 사용성은 학교의 서로 다른 Windows PC 두 대에서 확인한다.
