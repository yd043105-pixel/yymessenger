# 할 일 확인 등록과 D-Day

2026-10-13 · 교사용 Windows PC 메신저 · 프로그램 버전 1.0.0.

받은 메시지의 요청 문구와 날짜를 교내 서버에서 규칙으로 찾아 추천 항목에 저장한다. 외부 AI API나 외부 본문 전송을 사용하지 않는다. 메신저와 학교 서버의 기존 통신은 사용한다.

교사는 원문과 추출된 제목·기한을 확인하거나 수정하고 **확인 후 등록**을 누른다. 이후 진행 중인 할 일에 날짜와 D-Day를 함께 표시한다.

| 기한 | 표시 예시 |
| --- | --- |
| 3일 남음 | 2026.10.16 · D-3 |
| 오늘 | 2026.10.13 · D-Day |
| 이틀 지남 | 2026.10.11 · 기한 지남 2일 |
| 기한 미지정 | 기한 없음 |

위 예시는 2026-10-13을 기준으로 한 표시 예다. 실제 계산은 한국 날짜로 기한에서 오늘 날짜를 뺀 달력 일수다. 시간 단위 카운트다운은 아니다. 창을 열어 둔 동안 날짜가 바뀌면 목록과 선택한 항목의 표시를 갱신하며 수정 중인 입력 내용을 덮어쓰지 않는다.

진행 중인 항목을 먼저 기한순으로 정렬한다. 기한이 지난 일·오늘 마감·다가오는 기한·기한 없는 일 순서이며 추천 확인 대기와 완료/제외 항목은 뒤에 둔다. 서버가 전체 목록을 정렬한 후 페이지를 나누므로 다음 페이지를 열어도 순서가 유지된다. 완료/제외한 항목에는 과거 기한만 표시하고 D-Day는 표시하지 않는다. 기한이 지나도 자동 완료 처리하지 않는다.

기존의 원문 열람·직접 추가·제목/기한 수정·완료/제외 기능을 유지한다. 날짜가 불명확하면 추천은 기한 없이 나오므로 확인할 때 기한을 직접 지정할 수 있다. 이번 D-Day UI 변경은 PC 메신저에 적용했으며 휴대폰 앱의 별도 할 일 화면을 추가한 작업은 아니다.

검증: Server·Desktop 빌드 경고/오류 0, 기존 네이티브 화면 시운행을 포함한 `node tests/smoke.mjs --ui --skip-native-input`에서 63개 통과. 네이티브 할 일 화면의 확인 검사에 연말 D-1·D-Day·기한 지남·기한 없음·완료 표시를 포함했다. 111개 가상 항목으로 두 페이지의 전체 기한순 정렬·중복 없음도 확인했다. 원격지원의 실제 키보드 주입 1개는 명시적으로 제외했으며 할 일 기능 검증과 별개다. 실제 자정까지 대기하거나 PC 시계를 변경한 시험은 하지 않았다.
