# 교직원·학생·학부모 모바일 운영

2026-10-15 · 버전 1.0.0. 설치·빌드·서명·출시의 최신 절차는 [플랫폼 운영 안내](platform-deployment-guide.md)에 정리했다.

- 교직원은 `여양고 교무실` (`kr.school.yeoyang.teacher`), 학생·학부모는 `여양고 학교 소식` (`kr.school.yeoyang.family`)을 각각 설치한다. `Family`는 빌드 옵션 이름이며 제품명은 학생·학부모용 학교 소식 앱이다.
- 교내 업무 서버는 개인 쪽지·첨부·학사일정·특별실·상담 개설을, 학교 소식 서버는 대상별 공지·학생/학부모 계정·시간표·상담 신청을 처리한다. 급식 NEIS 연동은 현재 구현을 확인하지 못해 별도 개발·검증 과제다. 개인 교직원 쪽지·채팅·제출 파일을 외부 학교 소식 서버에 복제하지 않는다.
- 두 서버는 다른 계정·데이터·접근망으로 격리한다. 학교 회선을 사용하면 공개 역할에만 Cloudflare Tunnel을 설치한다. 물리 PC 한 대의 격리 방법은 학교 담당자가 검증한다. 교무실 앱의 업무 기능은 교내 Wi-Fi 또는 학교 VPN에서 사용한다.
- 가입·최초 활성화는 학교가 확정한 약관 정책 파일이 있어야 운영 모드에서 가능하다. 학생 등록·승인과 교직원 개인 활성화, 학부모 임시계정·다자녀 연결 절차를 구분한다. 운영 기본 보호자 연결은 학교 확인이며, 코드 즉시 연결은 학교 정책 승인 설정이 필요하다.
- 학교 소식의 **모든 공지 첨부**는 JPG/PNG, 한 장 200,000바이트, 공지당 최대 5장으로 제한한다. 권한을 검증해 공지 안에 표시하며 다운로드 기능을 제공하지 않는다. 첨부는 업로드 완료일부터 최대 30일이다. 이것은 교직원 내부 자료의 100MB 제한과 다른 정책이다.
- 앱은 HTTPS 인증서 검증을 유지한다. 세션은 플랫폼 보안 저장소에 보관하고 로그아웃·계정 변경 시 폐기한다. Android 화면 캡처 제한·백그라운드 가림과 iOS Keychain·화면 가림을 사용하지만 단말 전체 보안을 보장하지 않는다.
- 현재 앱 열기·새로고침으로 정보를 조회한다. FCM/APNs 백그라운드 푸시는 미구현이다. 실제 Android/iPhone 시험과 운영 HTTPS·VPN·푸시·스토어 심사는 별도로 진행한다.

시간표 담당자는 기초시간표와 일자별 변경 파일을 올린다. 해당 날짜 변경이 없으면 기초시간표를 사용한다. 학생별 수강 명부가 없는 동안 학급 시간표를 기준으로 확인한다. 급식 자동 연동은 현재 호출·화면 구현부터 확인·개발해야 하며 NEIS 키·학교 코드 설정만으로 완료됐다고 안내하지 않는다.
