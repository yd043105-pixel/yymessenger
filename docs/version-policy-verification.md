# 배포 전 1.0.0 버전 확인

2026-10-08 학교 담당자의 요청에 따라 PC·모바일·웹 버전을 1.0.0으로 통일했다. 배포 지시가 있을 때까지 버전과 업데이트 안내 순서 2를 유지한다. 이번 수정으로 태그·릴리즈를 생성하거나 공개하지 않는다.

## 확인한 범위

- `scripts/Build.ps1 -HeadlessTests`: 잠금 파일 복원, 세 프로젝트 빌드, 기능 검사, Windows x64 독립 실행 패키지 생성에 성공했다.
- `node tests/smoke.mjs --ui --skip-native-input --package`: 독립 실행 배포본과 실제 WPF 화면 검사 56개가 통과했다. Windows 키보드 직접 입력 1개는 명시적으로 제외했다.
- 외부 공지 17개, 발신 연결·장애 복구 7개, 서비스 데이터 폴더 분리 2개, 업데이트 표시 조건 8개, 원격 검사 도구 1개가 통과했다. 중복 실행한 서버 검사를 제외한 기능 검사 합계는 91개다. 방화벽 검사는 모의 환경에서 수행했고 실제 방화벽을 바꾸지 않았다.
- `Build.ps1 -Version 1.0.1`은 빌드 전에 버전 불일치로 거부됐다. 내장 버전은 1.0.0, 안내 순서는 2를 유지했다.
- 배포 PC 실행 파일의 제품 버전, 교직원 웹·외부 공지 웹의 내장 안내 버전, 패키지 `VERSION.txt`가 1.0.0이었다. 생성한 Windows ZIP의 SHA-256 해시도 일치했다.
- MSBuild로 모바일 표시 버전 1.0.0과 내부 빌드 번호 2를 확인했다. 내부 빌드 번호는 앱에 표시하는 버전과 별개다.
- `scripts/Build-Mobile.ps1`로 Android Debug APK를 다시 생성했으며 경고·오류가 없었다. 생성한 APK의 실제 매니페스트를 `aapt2 dump badging`으로 읽어 표시 버전 1.0.0과 내부 빌드 번호 2를 확인하고 SHA-256 기록을 갱신했다. 로컬 시험용 서명이며 스토어 출시 파일은 아니다.

이번 버전 확인은 학교 실제 운영 PC 간 원격 지원, iOS 빌드·서명, 스토어 배포를 검증한 기록이 아니다. 이전 Android 에뮬레이터와 웹 시운행 기록은 `docs/update-notice-verification.md`에 당시 버전 그대로 보존한다.
