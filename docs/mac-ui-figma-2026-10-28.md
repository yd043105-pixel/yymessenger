# Mac 화면 · 기존 PC 메신저와 톤 통일

초기 Mac 화면은 교사용 모바일 앱의 넓은 버튼과 하단 메뉴를 그대로 사용했다. 이번 변경은 기존 Windows 메신저의 정보 밀도와 색상·간격에 맞춰 Mac의 탐색·메시지함·작성창을 다시 구성한 작업이다. 네이티브 Mac Catalyst 앱을 유지하며 서버·권한·저장 구조를 바꾸지 않았다. 버전은 1.0.0이다.

연결된 세 계정 모두 Figma MCP 한도를 반환했다. 이후 Figma 웹 편집 화면에서 기존 PC 작성창을 복제하고, Mac에 없는 예약·제출 옵션·서식 편집·임시저장 버튼을 복제본에서 제거했다. 제목과 첨부 안내를 바꾸고 보내기를 오른쪽에 정렬했다. 원본 PC 화면은 보존했다. 새 작업본은 편집 가능한 오토레이아웃·글자·버튼 인스턴스이며 전체 화면 이미지를 붙인 것이 아니다. PNG는 Figma의 내보내기 기능으로 저장했다.

기본 강조 `#245BC6`, 본문 `#182C47`, 보조 글자 `#5A6B82`, 구분선 `#DFE7F1`, 선택 배경 `#EAF0FC`, 화면 배경 `#F3F6FB`, 내용 `#FFFFFF`를 기존 코드와 공유한다. 기존 브랜드·메뉴 SVG를 재사용한다. Figma의 한글 글꼴은 Noto Sans KR이고 실제 Mac은 운영체제 한글 글꼴을 사용한다. Catalyst의 표시 배율을 고려해 본문 글자 크기를 보정했다. 새 웹 화면이나 외부 글꼴 라이브러리를 추가하지 않았다.

## 실제 Mac 변경

- 넓은 메뉴 버튼을 작은 아이콘·글자 레일로 변경했다. 메시지와 학교 업무의 카테고리 배경을 다르게 하고, 짧은 창에서는 글자 중심으로 바꿔 메뉴 전체를 표시한다. 중복 모바일 하단 메뉴는 제거했다.
- 메시지 목록과 본문을 나란히 배치했다. 목록은 한 줄 생략 제목·보낸 사람·시각으로 구성하고 검색·미확인 필터·페이지 이동을 유지한다. 본문 제목도 한 줄로 표시하며 답장은 본문 스크롤 밖 하단에 둔다.
- 메시지 열람 성공 후 해당 목록 항목의 미확인 표시와 굵기를 갱신한다. 읽음 처리는 기존 서버 API의 성공 응답을 따른다.
- 작성창은 작은 상단, 받는 사람 수와 보조 버튼 한 줄, 두 줄 수신자 스크롤, 제목·본문, 얇은 첨부 영역, 하단 보내기로 정리했다. 수신자 제거·나에게 전송·파일 첨부와 중복 전송 방지 ID를 유지한다.
- 파일 업로드 중에는 보내기를 막고 오류는 현재 작성창에 표시한다. 메신저 공통 오류는 항상 보이는 하단 영역에 표시한다.
- 조직도는 부서별 묶음과 이름·직책·접속 상태로 표시한다. 로그인·로그아웃·창 전환 때 메시지 내용이 로그인 화면에 남지 않도록 한다.

macOS의 기본 창 버튼은 유지한다. Mac에서 아직 지원하지 않는 Windows 기능은 모양만 있는 버튼으로 추가하지 않았으며, 지원 범위는 [Mac 운영 안내](mac-operations.md)를 따른다.
