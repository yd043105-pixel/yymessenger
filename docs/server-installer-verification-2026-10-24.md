# 서버 설치 마법사 검증

2026-10-24 · 1.0.0 · 공개 릴리즈 없음

`installer/SchoolMessengerServer.iss`와 기존 Inno Setup 도구로 서버 전용 EXE를 제작했다. 실제 배포본은 관리자 권한으로 Program Files에 설치하고, 시험본은 별도 설치 ID를 사용하여 임시 폴더에 사용자 범위로 설치한다. 업무 서버 선택에는 관리자 메신저가 포함되고, 학교 소식 서버 선택에는 외부 앱 서버만 설치한다.

`tests/server-installer.ps1`의 7개 검사 통과:

1. 선택한 업무 서버·관리자 메신저·운영 도구가 설치되고 미선택 학교 소식 서버는 설치되지 않음.
2. 재설치·업데이트가 사용자가 추가한 운영 설정·가상 첨부·외부 비밀 파일을 보존함.
3. 더 높은 숫자 버전이 설치되어 있으면 낮은 버전 덮어쓰기를 거부함.
4. 설치된 실제 서버 EXE가 격리된 루프백 주소로 실행됨. 실행 중 업데이트·제거를 거부하고 서버를 강제 종료하지 않음.
5. 다른 경로에서 실행한 별도 가상 서버는 설치를 막지 않고 종료되지 않음.
6. 프로그램 제거가 실제 가상 서버 DB·첨부·추가 설정·외부 비밀 파일을 보존함.
7. 학교 소식 서버만 선택한 설치·제거·재설치가 동작하고 서버 예약 작업을 등록하거나 바꾸지 않음.

세부 결과는 `artifacts/server-installer-checks.json`, 시험 로그는 해당 JSON의 `testDirectory`에 있다. 운영 학교 자료·외부 메일·Cloudflare·방화벽을 사용하거나 수정하지 않았다. 실제 관리자 권한 요청 화면, 학교 보안 제품의 허용, 운영 예약 작업의 중지·등록 해제와 재부팅은 학교 현장에서 확인해야 한다. 설치 프로그램은 예약 작업을 읽어서 활성 작업이 있으면 업데이트를, 등록된 작업이 있으면 제거를 차단하지만, 이번 검사는 실제 운영 작업을 생성해 차단을 유도하지 않았다.

배포 전달 목록에 서버 설치 EXE와 SHA256을 추가했다. 기존 ZIP은 수동 배치용으로 유지하며 교사용 설치 EXE와 설치 식별자를 구분한다. 향후 GitHub 검사·릴리즈 첨부에도 서버 설치 제작과 검증을 연결했다. 새 태그·공개 릴리즈·학교 서버 설치는 실행하지 않았다.
