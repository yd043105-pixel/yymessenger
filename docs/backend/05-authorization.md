# 권한·현재 관계

숨긴 버튼이 아닌 서버가 판정한다. 인증·CSRF·계정 활성·버전·기기 세션 뒤에 리소스별 권한을 적용한다.

| 리소스 | 허용 |
| --- | --- |
| 개인 쪽지·첨부 | 발신자 또는 실제 수신자. 관리자라는 이유로 열람 불가 |
| 채팅·설문 | 저장된 참가자·수신자; 결과는 소유자 정책 |
| 공지·첨부 | 현재 학급/분반/보호자 관계와 저장된 대상·제외·회수 상태 교집합 |
| 학생·보호자 시간표 | 현재 본인 또는 연결된 자녀 학급; 임시/대기 회원 불가 |
| 교사 시간표 | 연결 검증된 교사 ID; 담당 시간표 |
| 제출 파일·ZIP | 본인 제출, 요청 발신자의 수합; 타 수신자 제출 열람 불가 |
| 예약·학교 일정 | 별도 담당자 권한, 본인 예약, 버전·시간 충돌 검사 |
| 계정·명부·심사·백엔드 상태 | 별도 서버 관리자 정책 |
| 교내 관리자 승격·관리자 변경 | BackendRoot의 최고관리자 ID만 |
| 기기 로그인 폐기 | 본인 계정만 |

공지 대상은 발송 때 확정하고 학급·분반 이동이나 자녀 연결 해제 시 폐기한다. 관계 Stamp/소속 ScopeVersion으로 재연결·재등록이 예전 비공개 공지 접근을 되살리지 않는다. 대상으로 선정된 학생의 담임도 기존 수신 규칙을 유지한다.

최고관리자 구분은 이번 교내 계정 승격·관리자 편집 경로에 적용한다. 공개 서버의 현재 관리자는 별도 계정이며 자기 역할 승격 경로가 없다. 모든 기존 관리자 기능을 다단계 관리자 등급으로 전면 재설계한 상태는 아니다. 새 관리자 권한 경로는 이 규칙을 함께 적용해야 한다.

현재 달력은 교직원 업무 범위다. 학생/보호자·학년/학급/분반 달력 범위의 전면 구현은 별도 미완료 항목이며 기존 일정을 공개하지 않는다.
