중간 실패: 관리자 생성 검사 코드를 잘못된 회원가입 위치에 추가한 빌드 오류를 수정했다. 테스트 중 열린 서버 DLL 잠금은 테스트 종료 뒤 재빌드로 해소했다. 추가 테스트의 잘못된 특별실 경로를 기존 API 경로로 고쳤다. 실제 동시 사용자 검사가 IP 공통 한도를 드러내 인증 뒤 사용자별 판정으로 수정했다. 합성 테스트의 SQLite 연결에 30초 busy_timeout을 적용해 백그라운드 쓰기와의 경합을 기다리도록 했다. 학생 연결 해제가 고유번호를 폐기하는 기존 규칙에 맞춰 검사에서 새 번호를 조회했다. 이러한 수정 뒤 통과한 결과만 위 표에 반영한다.

초기 16개 단기 추가 검사를 23개로 확장했다. 100계정 합성 동시 로그인/발송 부분은 약 7초였으며 사용자 생성 준비 시간·일반 네트워크 지연·학교 장기 부하를 포함한 성능 수치가 아니다. 실행 파일·앱 설치 패키지 재배포와 스토어 검사는 하지 않았다.

최종 서버 보완 뒤 backend-hardening 23개와 smoke --features 57개를 다시 실행해 모두 통과했다. 발신자 동기화 기록과 자동 미제출 알림의 영속 이벤트도 포함한다. 개인정보·운영 미확인 항목과 Windows 입력 SKIPPED는 그대로 유지한다.

최초 추가 CI의 Windows 항목은 테스트 실행 전에 Build.ps1의 UTF-8 BOM이 사라져 Windows PowerShell 5에서 한글을 잘못 해석하는 파싱 오류로 실패했다. BOM을 복원하고 해당 PowerShell 파서로 확인한 뒤 CI를 다시 실행했다. 서버 기능 검사 실패와 구분한다.

iOS 첫 실행은 자녀 연결이 성공하고 실제 자녀가 표시되었지만 기존 “자녀 연결 완료” 문구를 기다리는 검사에서 실패했다. 서버 응답 문구와 실제 정회원/자녀 표시를 함께 기다리도록 검사만 맞췄다. 설정 설명도 개발 즉시 연결과 운영 학교 확인에 모두 맞는 문구로 수정했다. 이후 CI 결과는 별도 실행을 확인한다.

최종 추가 범위에는 계정 버전이 지난 세션 목록 숨김과 공개 서버의 합성 보호자 100계정 동시 로그인/세션 분리를 포함했다. 보호자 계정 준비는 테스트 DB의 합성 자료로 수행했으며 회원가입·승인 부하를 측정한 것으로 표시하지 않는다.
