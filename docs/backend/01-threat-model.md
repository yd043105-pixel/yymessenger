# 위협 모델

2026-10-13 · 개발 보안 점검. 법률 준수·운영 보안 인증을 뜻하지 않는다.

보호 대상은 교직원 쪽지·첨부, 학생 명부·소속, 보호자 관계, 공지 열람 이력, 시간표, 로그인·서버 연결 키, 백업이다. 공격자는 익명 외부 사용자, 권한을 넘어서려는 로그인 사용자, 유출된 쿠키·학생 번호·연결 키 보유자, 감염된 단말이다. 서버 운영체제 관리자와 승인된 명부 담당자는 별도 신뢰 영역이며 앱 코드만으로 이들의 악용을 막았다고 주장하지 않는다.

| 경계·공격 | 영향 | 현재 방어·이번 변경 | 남은 확인 |
| --- | --- | --- | --- |
| 외부 앱 → 공개 서버 | 계정·학생 데이터 탈취 | HTTPS, 쿠키 보호, CSRF, 계정 잠금, 현재 소속·연결·대상 검사, 기기별 세션 해제 | 실제 인증서·도메인·기기·보호자 확인 |
| 공개 서버 → 교내 업무망 | 사적 업무 데이터 유출 | 공개 서버에는 쪽지·원격 API 없음. 교내에서만 연결 시작 | 실제 방화벽·VPN·서비스 계정 ACL |
| 교내 → 공지 연결 위조·재전송 | 대리 공지·대상 확대 | 서비스 ID·키 ID·본문 HMAC·시간·난수, DB 중복 차단, 기존 대상 스냅샷 | 키 보관·교체 훈련, 서버 시계 |
| 오래된 쿠키·권한 | 탈퇴·이동 후 열람 | 계정 버전+기기별 세션 DB 검사, 관계 Stamp·ScopeVersion | 실기기 로그아웃·OS 캐시 |
| 학생 번호 추측·유출 | 타 자녀 열람 | 암호학적 8자리 번호, 계정/IP 제한, 운영 기본 학교 확인 대기 | 본인확인 방법·학교 책임자 승인 |
| 악성·변조·만료 첨부 | 감염·과잉 보관 | 크기·서명·운영 AV 차단, 새 파일 SHA256, 업로드 완료부터 30일, 다운로드 재검사 | 실제 AV, 기존 파일 전수 검사, 단말 저장본 |
| 서버 중단·중복 요청 | 분실·중복 발송 | 메시지와 알림 트랜잭션, 영속 큐, DB 요청 키, 안정된 순번 | 전원 장애·대용량 장기 부하 |
| 백업 복원 | 이전 권한·파일 부활 | 정지 상태만 복원, 무결성 검사, 복원 전 백업, 세션·초대·교사 증명 폐기 | 별도 디스크 복구, 키·설정 동시 복구 |
| 운영자 감사 조작 | 추적 상실 | 앱 감사 추가 전용, UPDATE/DELETE 차단 | OS 관리자는 DB를 바꿀 수 있음. 외부 감사 보관 필요 |

위험 등급은 실제 노출 조건을 포함해 `10-security-audit.md`에서 관리한다. 원격지원 화면·입력, 암호·학생 번호·인증 토큰·메시지 본문을 감사 로그에 기록하지 않는다.
