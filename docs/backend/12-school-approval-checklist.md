# 학교 검토·학운위 준비

이 문서는 검토 항목이며 통과·법률 적합성을 선언하지 않는다. 약관 초안을 운영 확정 문구처럼 제공하지 않는다.

| 학교 결정 | 검토할 내용 | 현재 |
| --- | --- | --- |
| 운영 주체·책임자 | 학교/처리자·문의 창구·계정/명부 담당자·사고 연락 | 미확정 |
| 학생·학부모 개인정보 | 수집 항목·목적·법적 근거·보관 기간·거부 시 영향·동의/안내 구분·필요한 대리인 절차 | 검토용 초안 |
| 보호자 신원/관계 | 학교 기록 대조 방법·접수 채널·담당자·부정 연결 신고·다자녀/관계 변경 | 운영 기본 학교 확인 대기 |
| 번호 즉시 연결 | 번호 유출 시 자녀 데이터 노출 위험·담당 책임·대체 확인 | CodeOnly 운영 승인 기본 false |
| 학생 명부 | 일괄 등록 항목·권한·전학/졸업/학년 변경·수강 목록 제공 | 기존 기능과 실제 양식 대조 필요 |
| 게시 대상·담임 | 학급/분반·개별/제외·담임 수신·민감 공지·회수·보호자 열람 | 서버 검사 유지 |
| 퇴직·졸업·탈퇴 | 정지·관계 해제·내보내기·삭제/익명화·감사 보존 예외 | 정책·전면 수명주기 작업 남음 |
| 첨부·백업 | 30일 만료·별도 저장 사본·백업 주기/기간·암호화·삭제 책임 | 기본 정책 구현, 운영 확정 필요 |
| 외부 접속 | 도메인/인증서·교직원 VPN·공개 최소 API·서버 분리·위탁/제공 | 실환경 확인 전 |
| 푸시·단말 | 동의·철회·일반 문구만 알림·잠금 화면·분실·토큰 해제 | 미구현 |
| 원격지원 | 매회 동의·조회/제어 구분·짧은 시간·업무용 범위·감사 | 기존 P2P 유지 |
| 시범 운영·지원 | 소수 교직원/학급·오류/의견 창구·되돌리기·교직원 안내 | 운영 일정 미확정 |

학교가 실제 문구를 확정한 후 Registration:PolicyFile의 approvedForProduction을 승인 절차에 따라 설정한다. 코드가 이 값을 자동 승인하지 않는다. 공개 출시·실제 공지·학생 자료 입력·방화벽 변경은 이번 로컬 작업에서 하지 않았다.
