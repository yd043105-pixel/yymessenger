여양고 온라인 교무실 — 여기서 시작하세요
2026-10-24 / 아직 정식 배포 전 / 버전 1.0.0

현재 서버 설치 EXE 기준의 최신 순서입니다.
저장소 분리와 자동업데이트 제작은 나중에 진행합니다. 지금은 EXE 수동 설치입니다.

1. 먼저 [02_설명서] 폴더를 여세요.
   [00_기기별_설치와_테스트순서.txt]를 먼저 읽으세요.
   서버 / Windows PC / Android / iPhone의 우선순위·파일 경로·시험 방법을 적었습니다.
   Cloudflare를 자세히 설정할 때는 [01_처음설치부터_Cloudflare까지.txt]도 참고하세요.
   무엇을 준비하고, 어느 컴퓨터에서, 어떤 순서로 할지 설명했습니다.

2. 프로그램을 찾을 때는 [01_설치파일] 폴더를 여세요.
   01_서버PC : server-setup EXE로 서버 설치. ZIP은 수동 배치용입니다.
              업무 서버 선택 시 관리자 메신저도 함께 설치됩니다.
   02_교사PC : 일반 교사 PC용 설치 EXE
   03_안드로이드 : 교사용 teacher APK / 학생·학부모용 family APK
   04_iOS : Mac 전달용 최신 소스 ZIP
   아이폰 설치용 IPA는 아직 없습니다. 제작 안내를 먼저 확인하세요.

3. 01_설치파일의 기기별 폴더에는 실제 파일이 있습니다.
   필요한 폴더와 SHA256SUMS.txt를 USB 등 학교가 허용한 방법으로 복사하세요.
   설명서의 .lnk는 바로가기이므로 설치파일 대신 전달하지 마세요.
   APK는 Android 시험용입니다. 실제 학교 서버 설치·공개는 별도로 진행해야 합니다.

4. 실제 작업은 서버 준비 → 서버 실행 → 관리자 계정·자동검색·자동 구동 설정
   → 교사 PC 2대 → 휴대폰 → 재부팅·백업 복원 시험 순서입니다.
   02_설명서의 첫 안내에 이 PC에서만 화면을 시험하는 방법도 있습니다.

나머지 폴더의 용도
  artifacts : 빌드 결과 원본, 시험 결과 JSON, 화면 이미지
              logs = 모아 둔 실행 로그. 날짜별 중간 빌드 대신 01_설치파일을 사용하세요.
  docs      : 운영·기능·설계·검증 문서. README.md가 전체 목차입니다.
  config    : 설정 예시. 실제 값이 들어간 운영 설정과 구별하세요.
  src       : 프로그램 개발 소스
  scripts   : 빌드·운영·정리 스크립트
  tests     : 자동 검증 코드
  installer : Windows 설치 마법사 제작 코드
  .github   : GitHub 자동 검사·릴리즈 준비 설정
  .git      : 소스 변경 이력
  .tools / .test-data / .stitch / .dorms-check : 개발 도구·시험·참고 자료

개발 소스와 도구의 경로는 빌드 연결을 유지하기 위해 그대로 두었습니다.
이 폴더 전체를 교사나 학부모에게 전달하지 마세요. 필요한 설치 원본만 전달하세요.
루트의 시작-교사용.cmd / 시작-로컬체험.cmd는 배포 폴더용 파일입니다.
현재 개발 폴더에서는 실행하지 마세요. PC 설치는 01_설치파일을 이용하세요.

빌드를 다시 한 뒤 바로가기·로그를 정돈하려면 개발자가 실행:
  powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Organize-Workspace.ps1
학교 서버 설치를 자동으로 수행하는 명령은 아닙니다.

에듀집 등록 준비: [03_에듀집_등록준비]의 [00_먼저읽기_입력준비안.txt]부터 읽으세요.
공식 서식 / 학교 확정 전 작성자료 / 검증 요약으로 구분했습니다. 검토용 초안을 완성 제출본으로 올리지 마세요.
학교별 관리자 설정은 02_설명서의 [12_에듀집등록과_학교별설정]을 참고하세요.
