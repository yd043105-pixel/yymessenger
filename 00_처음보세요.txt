일반 사용자가 볼 폴더는 앞에 번호가 있는 네 곳입니다.

01_설치파일
  01_서버PC      : 서버 설치 EXE와 수동 배치용 ZIP
  02_교사PC      : 일반 교사 PC용 설치 EXE
  03_안드로이드  : 교사용 / 학생·학부모용 시험 APK
  04_iOS         : Mac 전달용 최신 소스 ZIP과 시뮬레이터 자료
  아이폰에 바로 설치하는 IPA는 아직 없습니다.
  다른 기기로 옮길 때는 실제 설치파일과 SHA256SUMS.txt를 함께 복사하세요.

02_설명서
  00_설치와_기능테스트_안내.pdf : 처음 시험할 때 먼저 읽을 4쪽 PDF
  01_설치와_접속              : 기기별 순서, 서버·Cloudflare·iOS 안내
  02_사용기능                 : 교직원 관리, 시간표, 가정통신문, 수강신청
  03_등록과_개인정보          : 에듀집·학운위·개인정보 검토 자료
  04_운영과_보안              : 보안 점검, 검증 로그, 오류 메일 설정
  99_전체문서_목차.lnk        : 원본 문서 전체 목차
  .lnk는 현재 PC에서만 사용하는 바로가기입니다.

03_에듀집_등록준비
  공식 서식 / 학교 확정 전 작성자료 / 검증 요약입니다.
  00_먼저읽기_입력준비안.txt부터 읽으세요. 검토 초안은 확정 제출본이 아닙니다.

04_화면미리보기
  실제 Windows 화면 5장과 앱·PC 디자인 시안 1장을 모았습니다.
  시안 파일은 실제 앱 구동 화면과 구분해서 표시했습니다.

개발·검증용 폴더 — 경로를 바꾸지 않고 유지합니다.
  src / scripts / tests / installer : 소스, 제작·운영 도구, 자동 검사, 설치 마법사
  config / docs                   : 설정 예시, 원본 설명서·설계·검증 문서
  artifacts                       : 최신 빌드 원본과 검증 결과
    logs / workspace-history      : 실행 로그, 과거 정리 기록·PR 작성 자료
    pdf-review                    : PDF 제작 때 확인한 중간 이미지
  output/pdf                      : PDF 제작 원본. 사용용 사본은 02_설명서에 있습니다.
  tmp                             : PDF 제작 등 임시 작업 공간
  sites                           : 별도 수강 설계 화면 작업 자료
  .git / .github                  : 소스 변경 이력과 GitHub 자동 검사 설정
  .tools / .test-data / .stitch / .dorms-check / .maintenance : 개발 도구·시험·참고 자료

루트의 global.json / Directory.Build.props / README.md / SECURITY.md 및 점으로
시작하는 설정 파일은 개발 도구가 사용하는 파일입니다. 임의로 이동하지 마세요.
배포용 시작 CMD 원본은 installer/launchers에 모았습니다. 설치는 01_설치파일을 이용하세요.

이 폴더 전체를 교사·학생·학부모에게 전달하지 마세요. 필요한 설치파일만 전달하세요.
실제 학교 서버 설정·외부 공개·iOS 서명·실기기 검증은 별도 작업입니다.

현재 설치파일을 그대로 둔 채 설명서와 화면만 다시 정리하려면 개발자가 실행:
  .\scripts\Organize-Workspace.ps1 -SkipDeliveryRefresh
빌드 후 설치파일 전달 사본까지 갱신하려면:
  .\scripts\Organize-Workspace.ps1
학교 서버 설치나 정식 릴리즈를 실행하는 명령은 아닙니다.
