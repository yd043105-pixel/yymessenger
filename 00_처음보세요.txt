2026-10-20 / 아직 정식 배포 전 / 버전 1.0.0

1. 먼저 [02_설명서] 폴더를 여세요.
   [00_기기별_설치와_테스트순서.txt]를 먼저 읽으세요.
   서버 / Windows PC / Android / iPhone의 우선순위·파일 경로·시험 방법을 적었습니다.
   Cloudflare를 자세히 설정할 때는 [01_처음설치부터_Cloudflare까지.txt]도 참고하세요.
   무엇을 준비하고, 어느 컴퓨터에서, 어떤 순서로 할지 설명했습니다.

2. 프로그램을 찾을 때는 [01_설치파일] 폴더를 여세요.
   PC 교사용 설치 EXE / 교사용 Android APK / 학생·학부모용 Android APK /
   서버 컴퓨터용 ZIP을 구분해 두었습니다.
   아이폰 설치용 IPA는 아직 없습니다. 제작 안내를 먼저 확인하세요.

3. 이 두 폴더 안의 화살표 아이콘은 원본을 가리키는 Windows 바로가기입니다.
   다른 컴퓨터에 전달할 때는 바로가기가 아니라 원본 EXE·APK·ZIP을 복사하세요.
   원본 찾기: 바로가기 우클릭 → 속성 → 파일 위치 열기.
   APK는 Android 시험용입니다. 실제 학교 서버는 아직 설치·공개하지 않았습니다.

나머지 폴더의 용도
  artifacts : 빌드 결과 원본, 시험 결과 JSON, 화면 이미지
              logs = 모아 둔 실행 로그 / previous-packages = 이전 패키지(사용 금지)
  docs      : 운영·기능·설계·검증 문서. README.md가 전체 목차입니다.
  config    : 설정 예시. 실제 값이 들어간 운영 설정과 구별하세요.
  src       : 프로그램 개발 소스
  scripts   : 빌드·운영·정리 스크립트
  tests     : 자동 검증 코드
  installer : Windows 설치 마법사 제작 코드
  .github   : GitHub 자동 검사·릴리즈 준비 설정
  .git      : 소스 변경 이력
  .tools / .test-data / .stitch / .dorms-check : 개발 도구·시험·참고 자료

개발 소스와 도구의 경로는 빌드 연결을 유지하기 위해 그대로 두었습니다.
이 폴더 전체를 교사나 학부모에게 전달하지 마세요. 필요한 설치 원본만 전달하세요.
루트의 시작-교사용.cmd / 시작-로컬체험.cmd는 배포 폴더용 파일입니다.
현재 개발 폴더에서는 실행하지 마세요. PC 설치는 01_설치파일을 이용하세요.

빌드를 다시 한 뒤 바로가기·로그를 정돈하려면 개발자가 실행:
  powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Organize-Workspace.ps1
학교 서버 설치를 자동으로 수행하는 명령은 아닙니다.
